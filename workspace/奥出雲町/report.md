# 営業支援レポート: 奥出雲町 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度当初予算（議会だより第79号掲載）

## エグゼクティブサマリー（5行以内）

- **消防格納庫整備事業46百万円（+繰越12百万円）・耐震性貯水槽設置事業39百万円が最重要案件。** 消防施設の計画的更新・整備。R8予算化済み。
- **新規3案件：ハザードマップ更新10百万円・Jアラート受信機器更新10百万円・避難所環境整備12百万円。** いずれもR8新規計上で発注時期近し。
- **消防設備整備事業（新規）24百万円。** 小型ポンプ付き軽積載車の配備。新規計上の車両案件。
- 防災拠点施設整備事業33百万円。防災拠点の機能向上。消防団救助能力向上資材整備（繰越9百万円：救命胴衣・デジタル無線機）も執行中。
- 常備消防は雲南広域連合（負担金298百万円）。その他消防・防災関連はすべて町直営。
