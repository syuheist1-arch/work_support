# 営業支援レポート: 赤磐市 / 防災
- 作成日: 2026-06-04
- 対象資料: 令和8年度当初予算案概要

## エグゼクティブサマリー（5行以内）

- **高機能消防指令センター設備中間更新＋消防救急デジタル無線設備更新の調達支援委託が消防施設整備67,297千円に含まれる。大型更新の前段階として今年度に調達支援を実施。**
- 消防費合計963,292千円（前年比+8.4%）。
- 防災情報配信アプリケーション保守1,650千円（新規）・体育館断熱改修・空調設備設計9,900千円（新規・避難所機能強化として明記）。
- 避難行動要支援者管理システム再構築6,820千円（拡充）。
- ため池ハザードマップ作成・廃止事業40,845千円（継続）。

## 次アクション提案

1. **【最優先】消防救急デジタル無線設備更新の調達支援業務の詳細確認**: 調達支援の仕様・委託先・スケジュールを消防本部へ確認。本体更新の仕様策定に関与するための第一歩。
2. **【情報収集】高機能消防指令センター中間更新の発注状況確認**: 令和8年度発注予定案件として既発注か否かを確認。
3. **体育館空調設計（9,900千円）の設計内容確認**: 避難所として整備。工事発注は次年度以降を想定。教育委員会へ問い合わせ。

## 要確認事項

- 消防救急デジタル無線設備更新の本体工事発注時期。
- 高機能消防指令センター中間更新の発注状況・仕様。
- 消防費963,292千円の内訳（常備消防費・非常備消防費・消防施設費等）。
