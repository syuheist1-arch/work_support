# 営業支援レポート: 智頭町 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度当初予算概要・広報ちづNo.890（2026年5月号）・工事発注予定一覧

## エグゼクティブサマリー（5行以内）

- 防災費9,947万円を計上。防災行政無線操作卓更新およびJ-ALERT受信機高機能化（更新）が主要事業。消防費はR7比3.9%（約2.7億円）へ大幅増（R7は2.7%・約1.8億円）。
- J-ALERT受信機更新工事は総務課・随意契約で4〜6月期に発注予定（令和8年度工事発注一覧記載）。令和8年6月3日時点で未発注。
- 浅見地区消防設備更新工事（消火栓2か所）が企画課・指名競争入札で7〜9月期に発注予定。
- 木造住宅耐震改修補助がR8〜R10年度の3年間限定で全額補助（上限内）に拡充。
- 防災行政無線操作卓更新は随意契約ベースで処理される可能性が高く、入札公告には出ない可能性あり。早期の担当課接触が重要。

## 議会・首長の関心（事実ベース）

※ 議事録は今回未収集（令和8年3月定例会議事録は公開未確認）。予算資料から読み取れる方針のみ記載。

- 広報ちづNo.890に「防災行政無線の操作卓を更新するとともにJ-ALERT受信機の高機能化を図ることで防災力向上に努めます」と明記。
- 消防費が構成比2.7%→3.9%と大幅増。無線・J-ALERT更新が主因として確認できる。

- 消防団は令和8年度に新団長就任。「地域防災力の向上と住民の安全・安心を守る活動に尽力」と表明。

2. **【今月中・随意契約に注意】J-ALERT受信機更新工事**: 4〜6月期発注予定で調査日時点未発注。随意契約のため公告なしで決定する可能性あり。総務課へ即時接触が必要。
