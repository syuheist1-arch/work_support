# 営業支援レポート: 三朝町 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度予算説明資料（2026-03-10公開、245ページ）

## エグゼクティブサマリー（5行以内）

- 消防費合計208,802千円のうち**防災基盤整備事業（消防施設）92,000千円が完全新規**計上。R7比+92,000千円の最大増額事業だが、予算資料内に個別詳細説明がなく用途（車両・格納庫等）が未確認。担当課への早急な確認が必要。
- 道路メンテナンス事業（橋梁補修）が104,400千円（R7比+87,200千円）と大幅増。辺地対策事業債・国庫補助を活用した橋梁補修工事・設計が今年度に集中。
- 防災広場整備事業が新規計上5,857千円。R7に整備計画策定、R8に実施設計→R9以降に工事化が見込まれる先行案件。
- 防災行政無線は維持管理のみ（16,714千円）。新規整備・デジタル化の記載なし。
- 倉吉消防署新庁舎建設工事の基本計画業務委託が広域連合（中部ふるさと広域連合）で新規計上。広域連合への別途アプローチが必要。

## 議会・首長の関心（事実ベース）

※ 議事録は今回未収集。予算資料から読み取れる方針のみ記載。

- 防災基盤整備事業（消防施設）92,000千円の完全新規計上が今年度の最大防災投資。
- 倉吉消防署新庁舎建設工事の基本計画業務委託が広域連合で新規開始。中期的に大型工事化見込み。
- 防災広場整備をR7計画策定→R8実施設計の段階で進めており、防災拠点整備に継続的に取り組む姿勢が見られる。
- 「ぼうさいこくたい2026 in 鳥取」開催経費130千円を消防団活動費に計上（鳥取県で開催）。

## 次アクション提案

1. **【最優先・令和8年度内】総務課への「防災基盤整備事業（消防施設）」内容確認**: 92,000千円の新規計上だが詳細不明。「消防施設整備の内容・発注時期・仕様を確認させてほしい」の切り口で即時接触。三朝町役場TEL: 0858-43-0111（代表）。
2. **【令和8年度内】建設水道課への橋梁補修アプローチ**: 104,400千円（R7比+87,200千円）の橋梁補修工事・設計の発注時期・対象橋梁を確認。
3. **【仕込み・R8〜9年度】防災広場整備工事への先行提案**: R8実施設計→R9以降工事化。設計段階からアプローチし工事仕様に関与できる体制を整える。
4. **【情報収集】鳥取中部ふるさと広域連合への倉吉消防署新庁舎情報収集**: 基本計画業務委託の内容・工事スケジュール・発注規模を把握。
5. **【並行】三朝町入札公告の確認**: 防災基盤整備・橋梁補修の公告が出次第即対応。
