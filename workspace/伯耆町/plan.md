# リサーチプラン: 伯耆町 / 防災

## 1. 調査目的
鳥取県伯耆町（人口約1万人の町）における令和7・8年度の防災関連予算・議会議論・入札動向を一次情報から把握し、新規提案先・補正予算の動き・共同調達/広域連携の余地を営業向けに整理する。町村規模を踏まえ、単独大型システム調達よりも避難所整備・消防団・自主防災・備蓄・耐震化・広域連携を主眼に、事実ベースで提案接点を特定する。

## 2. 収集対象（一次情報）
- 予算書:
  - 令和7年度 当初予算（成立済み・執行中） … 既定の防災事業の規模・内訳を確認するため
  - 令和7年度 補正予算（第1号以降、~令和8年5月時点まで） … 年度途中の追加・国補助連動の動きを把握するため
  - 令和8年度 当初予算 … 直近の新規/拡充事業＝最も鮮度の高い提案接点のため
  - ※当初/補正の別、款項目（総務費・消防費・土木費・衛生費等）レベルまで取得
- 議会会議録:
  - 令和7年第1回（3月）定例会～直近会期（令和8年第1回/3月定例会まで） … 予算審議・一般質問での防災テーマの首長/担当課答弁を把握するため
  - 委員会（総務常任委員会等、防災所管）会議録 … 事業の背景・課題認識・今後方針を確認するため
- 入札公告/入札結果:
  - 令和7・8年度の防災関連調達（避難所設備、備蓄、防災行政無線、ハザードマップ、耐震化工事、消防団装備等） … 実際の調達時期・規模・落札傾向＝具体的商談タイミングのため
- 各情報源のURLは創作せず、収集役に伯耆町公式サイト・鳥取県電子入札等から探索させる。

## 4. 各エージェントへの指示文（コピペ用）

### → collector-budget
伯耆町（鳥取県西伯郡）の公式サイトを起点に、以下の予算情報を収集し workspace/伯耆町/budget_raw.md に保存してください。
- 対象: 令和7年度 当初予算、令和7年度 補正予算（全号）、令和8年度 当初予算
- 重点款項目: 消防費（消防団・常備消防負担金・防災対策費）を中心に、総務費（防災管理・自主防災・備蓄・防災行政無線・ハザードマップ）、土木費（治水・河川・浸水・土砂災害・橋梁）、衛生費（上下水道耐震化）、教育費（学校耐震・避難所指定施設）も対象。
- 各事業について「事業名／年度／当初・補正の別／金額／財源（国県補助の有無）／出典URL」を表形式で記録。
- 防災関連の入札公告・入札結果（避難所設備、備蓄、防災行政無線更新、ハザードマップ作成、耐震化工事、消防団車両・装備等）を伯耆町公式・鳥取県電子入札システム等から探索し、案件名・公告/開札日・予定価格/落札額・落札者を記録。
- 鳥取県西部の広域連携（西部広域行政管理組合の消防等）に伯耆町が負担金を出している箇所があれば併記。
- 原則: URLや金額を創作しない。見つからない情報は「未確認（探索範囲・想定情報源）」と明記。

### → collector-minutes
伯耆町議会の会議録（公式サイトまたは会議録検索システム）から、防災関連の発言を抽出し workspace/伯耆町/minutes_raw.md に保存してください。
- 対象会期: 令和7年第1回定例会（3月）～直近の定例会（令和8年第1回/3月想定）まで、および防災所管の常任委員会。
- 抽出キーワード: 防災、地域防災計画、国土強靱化、避難所、福祉避難所、ハザードマップ、防災行政無線、備蓄、耐震、河川・浸水・治水、土砂災害、消防団、自主防災組織、防災訓練、BCP、受援。
- 各発言は「会期・日付／発言者（議員名・町長・課長等）／質問または答弁の要旨／原文該当箇所／出典URL」で記録。
- 予算審議で防災事業に言及があれば優先抽出。
- 原則: 発言の有無・内容を創作しない。該当なしの会期はその旨を記録。

### → analyst-budget
workspace/伯耆町/budget_raw.md を読み、防災事業を以下8観点で分類・分析し workspace/伯耆町/budget_analysis.md に保存してください。
- 8観点: (1)地域防災計画/国土強靱化 (2)治水・河川・浸水・土砂災害 (3)建築物・橋梁・上下水道の耐震化 (4)避難所・指定緊急避難場所・福祉避難所 (5)ハザードマップ・防災情報システム・防災行政無線 (6)備蓄・物資・受援・BCP (7)消防・救急・消防団・自主防災 (8)防災教育・訓練
- 各観点ごとに令和7当初／令和7補正／令和8当初の金額を並べ、増減・新規・廃止を明示。
- 補正で計上された事業（国補助連動の可能性）を別掲。
- 入札公告と予算事業の対応関係（どの予算がどの調達になったか）を可能な範囲で紐付け。
- 出典が欠落・推測の箇所は明示する。

### → analyst-needs
workspace/伯耆町/budget_analysis.md と workspace/伯耆町/minutes_raw.md を突合し、伯耆町の防災課題と提案接点を workspace/伯耆町/needs_analysis.md に整理してください。
- 議会答弁で示された町の課題認識・今後方針と、予算/入札で実際に動いている事業を対応させる。
- 「すでに予算化＝直近商談」「議会で議論あるが未予算化＝先行提案余地」「広域連携・共同調達が主体の領域」を区別。
- 町村規模（人口約1万人）の制約を踏まえ、単独調達か広域連携/共同調達かの想定を観点ごとに付す（想定は事実と区別して明記）。
- 提案接点ごとに「根拠（出典）」「確度（事実/推測）」「想定アプローチ時期」を付す。

### → qa-editor
全成果物（budget_raw / minutes_raw / budget_analysis / needs_analysis）を統合し、営業担当向けサマリを workspace/伯耆町/report.md に作成してください。
- 構成: 1)エグゼクティブサマリ 2)予算ハイライト（年度比較） 3)議会での論点 4)提案接点リスト（確度・時期・想定調達形態付き） 5)要確認事項（出典欠落・未確認）。
- 事実と推測を必ず分離し、推測には「想定」と明記。出典URLを各記述に紐付け、欠落は「要確認」とする。
- 創作・断定を排し、確認できた一次情報のみを「事実」として扱う。
