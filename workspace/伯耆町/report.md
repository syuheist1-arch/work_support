# 営業支援レポート: 伯耆町 / 防災
- 作成日: 2026-06-02（R8予算追記: 2026-06-02）
- 対象資料: 予算（令和8年度当初予算説明資料概要 2026/02/25、令和7年度当初予算説明資料概要 2025/02/27、令和7年度補正第7号説明資料 2026/02/25）、議事録（令和7年第1回定例会 施政方針 2025/03/17）

## エグゼクティブサマリー（5行以内）

- 令和8年度一般会計87億600万円（合併以降最大）のうち消防費269,952千円（R7比△2.3%）。緊急防災・減災事業債はR7 42,800千円→R8 65,400千円（+52.8%）と大幅拡大し、防災行政無線更新設計・トイレトレーラー・避難所LED化の新規3事業が乗っている。
- 防災行政無線更新事業（13,966千円）が新規計上——整備後15年超の老朽化で機器更新設計に着手。令和8〜9年度に設計→工事と進む見込みで、提案タイミングは今が最適。
- 耐震性貯水槽整備（17,970千円）は継続（R7 31,370千円から減少、設置工事1基＋設計2基に縮小）。年次計画が続いており毎年の提案機会がある。
- 令和7年度施政方針で小澤町長が防災を第1施策に掲げ、地域防災計画・耐震改修促進計画の改定を明言。計画改定支援の商機が続く。
- 消防は西部広域行政管理組合が担当。町単独の通信（無線）・水利（貯水槽）・避難所インフラ更新が主な提案領域。

## 議会・首長の関心（事実ベース）

以下はすべて小澤敦彦 伯耆町長による令和7年第1回定例会 施政方針（2025/03/17）の発言。

1. **地域防災計画の改定**: 「能登半島地震の教訓や地球温暖化に伴う自然災害の頻発化・激甚化に対応し、防災・減災の備えを強化」し、「伯耆町地域防災計画の改定を行い、防災対策の更なる充実強化を図る」と明言。施政方針の第1施策「安心・安全な町づくりの推進」として位置付け。
2. **住宅耐震化・耐震改修促進計画改定**: 「建築物の耐震化は極めて重要な取組み」として「伯耆町耐震改修促進計画を改定するとともに、住宅の耐震改修に対して広報の強化と支援をする」と発言。
3. **耐震性貯水槽の年次設置**: 「西部消防局と協議しながら年次的に設置している耐震性貯水槽について、真野、須村地内での2か所の新設」と「水量不足が想定される2か所の設計委託費を予算化」と明言。
4. **重点ため池の監視システム設置**: 「重点ため池の監視システム設置や廃止工事」を継続実施すると発言。
5. **二部体育館の避難所指定整備**: 「二部体育館を災害時の指定避難所として位置付け、体育館周辺の舗装工事を実施する」と発言。

出典: https://www.houki-town.jp/new1/10/2/r266/r875/（令和7年度施政方針、2025/03/17）
