# 営業支援レポート: 伯耆町 / 防災
- 作成日: 2026-06-02
- 対象資料: 予算（令和7年度当初予算説明資料概要 2025/02/27、令和7年度補正第7号説明資料 2026/02/25）、議事録（令和7年第1回定例会 施政方針 2025/03/17）

## エグゼクティブサマリー（5行以内）

- 小澤敦彦町長が令和7年度施政方針の第1施策として「安心・安全な町づくりの推進」を掲げ、能登半島地震の教訓を明示的に引用して地域防災計画・耐震改修促進計画の改定を宣言した。
- 令和7年度消防費は前年比+9.20%（+23,283千円）増加し、耐震性貯水槽整備（31,370千円）・防災行政無線非常用電源更新（3,300千円）・Jアラート受信機更新（3,177千円）等ハード更新が集中している。
- 令和8年1月の島根県東部地震を受け補正第7号で災害復旧事業（自治公民館等16,000千円・公共土木14,275千円）が新規計上され、今まさに復旧発注が進む局面にある。
- 緊急防災・減災事業債（充当率100%・交付税算入70%）を積極活用しており、財政負担が軽い形での設備投資が続いている。
- 消防は西部広域行政管理組合消防局に委ねられており、装備・車両調達は組合側に当たる必要がある一方、町単独の水利・通信・避難所インフラ更新は町窓口への直接提案が有効。

## 議会・首長の関心（事実ベース）

以下はすべて小澤敦彦 伯耆町長による令和7年第1回定例会 施政方針（2025/03/17）の発言。

1. **地域防災計画の改定**: 「能登半島地震の教訓や地球温暖化に伴う自然災害の頻発化・激甚化に対応し、防災・減災の備えを強化」し、「伯耆町地域防災計画の改定を行い、防災対策の更なる充実強化を図る」と明言。施政方針の第1施策「安心・安全な町づくりの推進」として位置付け。
2. **住宅耐震化・耐震改修促進計画改定**: 「建築物の耐震化は極めて重要な取組み」として「伯耆町耐震改修促進計画を改定するとともに、住宅の耐震改修に対して広報の強化と支援をする」と発言。
3. **耐震性貯水槽の年次設置**: 「西部消防局と協議しながら年次的に設置している耐震性貯水槽について、真野、須村地内での2か所の新設」と「水量不足が想定される2か所の設計委託費を予算化」と明言。
4. **重点ため池の監視システム設置**: 「重点ため池の監視システム設置や廃止工事」を継続実施すると発言。
5. **二部体育館の避難所指定整備**: 「二部体育館を災害時の指定避難所として位置付け、体育館周辺の舗装工事を実施する」と発言。

出典: https://www.houki-town.jp/new1/10/2/r266/r875/（令和7年度施政方針、2025/03/17）
