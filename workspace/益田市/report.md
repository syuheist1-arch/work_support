# 営業支援レポート: 益田市 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度当初予算説明資料

## エグゼクティブサマリー（5行以内）

- **防災情報伝達基盤システム等管理運営費46,141千円が最重要案件。** 屋外拡声子局放送システム更新委託22,748千円・支持柱改修工事を含む。R8予算化済み。
- **積載車等整備事業費18,829千円（地方債18,200千円）。** 軽積載車2台（平成10年式・平成11年式）更新。老朽車両の更新案件。
- **消防費合計845,633千円（R7比+43,656千円）。** 常備消防費は益田地区広域市町村圏事務組合負担金693,339千円・六日市分遣所改修事業負担金38,320千円（新規）を含む。
- 消防施設費28,374千円（地方債21,000千円）。消火栓3基移設・消防ホース21本整備も計上。
- 防災対策費77,751千円（国県65,100千円）。備蓄品1,318千円・自主防災組織補助300千円も継続計上。

## 議会・首長の関心（事実ベース）

- 一般会計R7比+1,247,000千円と増加。消防費も+43,656千円増。
