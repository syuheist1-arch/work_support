# 営業支援レポート: 湯梨浜町 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度当初予算 総務課予算参考資料PDF（44ページ）

## エグゼクティブサマリー（5行以内）

- 消防費の大半は広域連合負担金（鳥取中部ふるさと広域連合）271,655千円（R7比+24,880千円）。常備消防の実態は広域連合側に移行しており、直接案件化には広域連合へのアプローチが必要。
- 消防車両購入事業18,690千円は20年以上経過した小型ポンプ積載車2台の毎年継続更新。今年度も同額・同規模で実施見込み。
- 消防庁舎建設費負担金14,321千円（R7比+8,542千円）は湯梨浜・琴浦・西倉吉消防署の建設資金償還。新規工事ではなく債務償還。
- 防災行政無線はMCA無線方式で保守点検のみ（6,107千円）。新規整備・デジタル化の記載なし。
- 地域未来交付金（地域防災緊急整備型）3,267千円（+1,772千円）で避難所資機材整備（大型扇風機・スポット等）。

## 議会・首長の関心（事実ベース）

※ 議事録は今回未収集。予算資料から読み取れる方針のみ記載。

- 消防費は広域連合負担金が中心。広域連合への負担金がR7比+24,880千円と増加しており、鳥取中部ふるさと広域連合の事業拡大を反映。
- 防災対策特別強化事業（防災特別対策官）を継続計上しており、専門職員による防災体制強化の姿勢が見られる。
- 防災行政無線はMCA無線方式。保守点検のみで新規整備・デジタル化の計画は今年度予算に見当たらない。
