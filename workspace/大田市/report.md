# 営業支援レポート: 大田市 / 防災
- 作成日: 2026-06-03
- 対象資料: 予算（令和8年度当初予算概要 2026/03/18、令和7年度比較値）、入札公告（令和7年度一覧・令和8年度一覧）

## エグゼクティブサマリー（5行以内）

- 令和8年度一般会計26,760,000千円（+3.0%）の中で消防費（款）は1,054,249千円・前年比△12.1%と逆行して減少。ただし消防救急無線・消防格納庫はR8に「実施設計」を計上しており、本体更新工事はR9以降に大型化する見込み。
- 防災対策事業が6,540千円→43,928千円と約6.7倍に急増（Jアラート・被蓄品・被災者支援システム・自主防災組織拡充が対象）し、防災ハザードマップ改訂事業（9,900千円）が新規計上された。今年度内に調達発生の可能性が高い。
- 消防救急デジタル無線（活動波）は平成27年度運用開始・令和8年度に設備更新の実施設計着手。R9〜R10年度に本体更新の大型案件が見込まれ、今が情報収集の好機。
- 石見銀山遺跡落石等対策事業88,700千円（防災対策事業債65,000充当）が毎年継続する安定した大型土木防災案件として存在する。
- 消防は大田市直営（広域組合委託ではない）。危機管理課・消防部通信指令課・建築営繕課が主な提案窓口。
