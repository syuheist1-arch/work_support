# 営業支援レポート: 大山町 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度当初予算（令和8年第2回定例会議案説明資料）

## エグゼクティブサマリー（5行以内）

- 常備消防費は西部広域行政管理組合負担金260,729千円（鳥取県西部広域）が中心。常備消防の実態は広域組合側に移行しており、大規模案件は広域組合へのアプローチが必要。
- **防災マップ（ハザードマップ）更新業務委託9,680千円が新規計上（防災・危機管理対策交付金充当）。** 鳥取県の中小河川浸水想定区域図見直しに伴う更新。今年度の最重要直接案件。
- 橋梁長寿命化修繕事業57,450千円（大和田橋外2橋補修工事40,000千円＋潮音寺橋設計12,650千円）と橋梁定期点検事業27,000千円（162橋）が土木防災系の主要案件。
- 防災行政無線は維持管理のみ（9,207千円・+1,834千円）。新規整備・デジタル化の記載なし。
- 単県急傾斜地崩壊対策事業（町負担金2,000千円）は令和8年度が最終年度（R7比△4,000千円）。

## 議会・首長の関心（事実ベース）

※ 議事録は今回未収集。予算資料から読み取れる方針のみ記載。

- 「安心で快適なまちづくり」を五本柱の一つに掲げ、防災行政無線管理・震災に強いまちづくりを推進。
- 防災マップを令和8年度に新規更新（前回令和元年度）。鳥取県の浸水想定区域図見直しに合わせた積極的対応。
- 橋梁162橋の計画的点検・修繕を継続実施。長寿命化修繕計画に基づく予防保全型の整備を継続。
