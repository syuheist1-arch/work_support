# 営業支援レポート: 真庭市 / 防災
- 作成日: 2026-06-04
- 対象資料: 令和8年度当初予算概要説明書

## エグゼクティブサマリー（5行以内）

- **消防救急デジタル無線設備機器更新及び再設定業務（債務負担行為、限度額382,462千円・令和8〜10年度）が最重要案件。3年間の大型更新で令和8年度に契約予定。**
- **水槽付き消防ポンプ自動車更新事業（債務負担行為、限度額108,596千円・令和8〜9年度）も令和8年度に発注予定の複数年契約案件。**
- 消防分署庁舎整備事業49,874千円（美新分署建替え設計・土地購入・旧蒜山分署解体）が令和8年度計上。
- 非常備消防施設等整備事業（債務負担行為、限度額47,140千円・令和8〜9年度）：消防ポンプ積載車更新。
- 消防費合計1,327,209千円（R7比△9.0%）。前年度の消防車両導入事業の反動減。
