# 営業支援レポート: 津和野町 / 防災
- 作成日: 2026-06-04
- 対象資料: 令和8年度当初予算書

## エグゼクティブサマリー（5行以内）

- **情報配信システム整備委託料8,668千円が最重要案件。** 災害対策費内。R8に計上された委託料で発注先・仕様確認が必要。
- **消防積載車購入17,416千円（緊急防災・減災事業債17,400千円・国庫補助2,893千円）。** 非常備消防費内。車両調達案件。
- 防災行政無線保守業務委託料5,225千円・個別避難計画作成業務委託料1,820千円も計上。
- **伝統的建造物群保存地区防災公共事業費補助金（国庫46,800千円・県6,300千円）。** 社会教育費に計上。伝統的建造物保護と防災を組み合わせた特徴的な案件。
- 消防費合計312,224千円（R7比+24,305千円）。常備消防は益田地区広域市町村圏事務組合への負担金231,054千円が中心。
