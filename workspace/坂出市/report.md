# 営業支援レポート: 坂出市 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度予算概要（坂出市財務課）

## エグゼクティブサマリー（5行以内）

- 一般会計319億6,350万円（前年比+20.5%）。消防費1,107,470千円（前年比+23,383千円、+2.2%）。
- **【最重要案件】消防通信指令施設整備（+103,000千円増）**。消防債91,700千円が計上されており、通信指令施設の更新が令和8年度の最重要投資案件と推定。
- **消防力整備（△129,300千円）**。前年度に実施した消防車両等の整備が一段落した可能性。
- 排水路整備が土木費内で+180,280千円大幅増。土木費全体も+18.0%増（2,241,436千円）。
- 消防費項別・目別詳細は予算書本体（未公開）で確認要。事業絶対値は未取得。

## 次アクション提案

1. **消防通信指令施設整備の内容確認**: 消防本部へ更新内容・発注スケジュールを確認。消防債91,700千円の充当事業か否かも確認。
2. **消防費詳細の入手**: 財務課へ詳細予算書（項別・目別）の入手または閲覧を依頼。
