# 営業支援レポート: 日吉津村 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和7年度当初予算（令和8年度は2026年6月3日時点で未公開）

## 重要注記

**令和8年度当初予算は2026年6月3日時点で日吉津村公式サイトに未公開。** 本レポートは令和7年度当初予算に基づく。令和8年度予算公開後の再調査が必要。

## エグゼクティブサマリー（5行以内）

- 消防費合計30,041千円（R6比+5,956千円）。災害対策費17,953千円（+5,698千円）がR7に大幅増。
- **J-ALERT更新業務委託料4,147千円がR7新規計上。** 防災行政無線（コスモキャスト）の維持管理・固定系デジタル無線設備点検も継続中。
- 防災行政無線は保守・更新フェーズ。新規大規模整備ではなく既存設備の維持管理が中心。
- 橋梁補修：村道5号線西川橋3補修工事23,100千円がR7計上。規模に比して大型案件。
- 県営農村地域防災減災事業市町村負担金3,968千円あり。
