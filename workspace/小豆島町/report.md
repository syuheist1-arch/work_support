# 営業支援レポート: 小豆島町 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度予算の概要・予算データ

## エグゼクティブサマリー（5行以内）

- 消防費457,327千円（前年比△4.3%）。消防施設費15,140千円（前年比**+284.3%**大幅増）が最注目。
- **【最重要案件】消防施設費+284.3%増（15,140千円）**：消防団車両・備品整備が主因。発注内容の確認が急務。
- **ため池防災対策特別事業（猪谷池改修）36,700千円**・防災重点ため池監視装置設置3,300千円が農林水産業費に計上。
- **港湾地震津波対策事業（池田港陸閘改良）25,000千円・室生北港水門改修14,000千円**が土木費に計上。
- 津波・洪水ハザードマップ整備10,000千円・民間住宅耐震診断・改修助成8,800千円も計上。

## 次アクション提案

1. **消防施設費の内訳確認**: 総務課（消防担当）へ消防団車両の車種・台数・発注スケジュールを確認。
2. **猪谷池改修工事の発注確認**: 農林水産課へ工事内容・発注時期を確認。
3. **池田港陸閘改良・室生北港水門改修の発注確認**: 建設課へ発注スケジュールを確認。

## 要確認事項

- 消防施設費15,140千円の内訳（消防団車両の車種・台数・防火水槽等）
- 防災諸費が前年比△94.4%と大幅減した理由
- ため池監視装置設置3,300千円の具体的設置箇所・発注時期
