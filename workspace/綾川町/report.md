# 営業支援レポート: 綾川町 / 防災
- 作成日: 2026-06-10
- 対象資料: 令和8年度当初予算書・予算概要

## エグゼクティブサマリー（5行以内）

- 消防費480,985千円（前年比**+90,020千円、+23.0%の大幅増**）。常備消防費が主因。
- **【最重要案件】消防ポンプ自動車75,064千円**（備品購入費・地方債75,000千円充当）が計上。
- **洪水土砂災害ハザードマップ修正業務2,541千円**・衛星電話設置工事2,262千円・災害対策備品12,548千円が新規計上。
- 防災士資格取得業務8,677千円・地域防災計画改定業務1,250千円・次期防災情報システム負担金901千円も計上。
- 農業水路等長寿命化・防災減災事業（県営負担金1,649千円）・ため池緊急整備事業（2,470千円）も計上。

1. **消防ポンプ自動車（75,064千円）の発注確認**: 総務課（消防担当）へ車種・発注スケジュールを確認。
