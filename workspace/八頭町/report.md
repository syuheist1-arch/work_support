# 営業支援レポート: 八頭町 / 防災
- 作成日: 2026-06-03
- 対象資料: 広報やず令和8年5月号別冊「八頭町の予算の概要」

## エグゼクティブサマリー（5行以内）

- 消防費4億1,916万円（3.5%）のうち東部広域行政管理組合負担金が2億9,998万円と大半を占める。消防署増改築・消防車両更新等が広域組合経由で進行中。
- 消防設備等整備事業費1,650万円で小型可搬ポンプ5台を今年度購入予定。全額に近い形で町債充当（1,570万円）。
- 防災行政無線は保守管理のみ（2,845万円）。新規整備・デジタル化の記載なし。
- 橋梁メンテナンス事業1億280万円（国費6,502万円・町債2,690万円）が土木費防災系で最大案件。橋梁点検・改良が継続発注。
- 斜面崩壊復旧事業（明辺地内）940万円が新規計上。急傾斜地崩壊対策負担金1,300万円も継続。

## 議会・首長の関心（事実ベース）

※ 議事録は今回未収集。予算概要から読み取れる方針のみ記載。

- 一般会計がR7比+3.0%増の積極的予算。消防費3.5%・土木費6.7%を確保。
- 鳥取県東部広域行政管理組合を通じた常備消防への投資（消防署増改築・車両更新）が継続中。
- 消防団員の準中型免許取得補助が令和8年度から消防団運営費に追加。
