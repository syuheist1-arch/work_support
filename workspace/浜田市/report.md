# 営業支援レポート: 浜田市 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度一般会計当初予算

## エグゼクティブサマリー（5行以内）

- **消防救急デジタル無線設備更新事業7,700千円（新規・地方債7,700千円・R8〜R12）が今年度の最重要案件。** R8は実施設計業務委託。共通波・活動波の更新でR8〜R12の多年度事業。
- **消防施設等整備事業85,161千円（地方債85,000千円）。** 小型動力ポンプ付軽積載車2台（今市分団）・消火栓新設13基・消防ポンプ車庫新築設計（岡見分団）等。
- **防災まちづくり事業45,502千円（地方債45,400千円）。** 常備消防ポンプ自動車（旭）更新を含む施設整備。
- 島根県防災行政無線ネットワーク再整備事業負担金457千円（新規・R8〜R12）。県主導の防災行政無線再整備への参加。
- 消防費合計1,513,630千円（R7比△61,006千円）。消防施設費はR7大型整備（261,564千円）の反動減。

## 議会・首長の関心（事実ベース）

※ 議事録は今回未収集。予算資料から読み取れる方針のみ記載。

- 消防救急デジタル無線の更新を新規事業として計上。耐用年数到来に対応。
- 防火水槽の50年経過劣化問題を把握し、調査点検事業（新規）を計上。
- 島根県の防災行政無線ネットワーク再整備に参加（新規・R8〜R12）。
- 本庁舎非常用電源設備更新事業（債務負担行為・R9：35,291千円）を翌年度に計画。

## 次アクション提案

1. **【令和8年度内・最優先】消防本部通信指令課への「消防救急デジタル無線設備更新実施設計」発注確認**: R8は設計委託。R9以降の本体工事に向けた仕様確認と関係構築が最優先。浜田市消防本部TEL: 0855-22-2612。
2. **【令和8年度内】消防施設等整備事業（85,161千円）の発注確認**: 軽積載車2台・消火栓13基の仕様・発注時期を確認。
3. **【令和8年度内】防災まちづくり事業（消防ポンプ自動車更新）の発注確認**: 消防ポンプ自動車（旭）の仕様・納期・入札方法を確認。
4. **【情報収集】島根県防災行政無線ネットワーク再整備の全体計画確認**: 県主導事業の詳細・浜田市の整備規模・R9以降の発注予定を把握。
