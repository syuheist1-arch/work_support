# 営業支援レポート: 三豊市 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度予算案の概要・建設工事発注見通し

## エグゼクティブサマリー（5行以内）

- 一般会計369億5,000万円（前年比△19.4%）。消防費1,417,520千円（前年比△18.0%）。骨格予算のため大幅減。
- **【最重要案件】消防施設一般経費56,121千円**に小型動力ポンプ付積載車等・高瀬町防災センター空調修繕工事が含まれる。
- **防災重点ため池水位計設置工事（繰越・3か所）**・**詫間水門水位計更新工事**・**自家発電機更新工事**が発注見通しに掲載。
- 防災一般費62,657千円：地域防災計画改訂・総合防災マップ改訂・備蓄物資整備・自主防災組織補助が計上。
- 骨格予算のため新規事業は補正予算（6月頃）に計上予定。補正後の消防・防災予算を再確認が推奨。

## 次アクション提案

1. **小型動力ポンプ付積載車の仕様・発注確認**: 危機管理課へ車両種別・発注時期を確認。
2. **ため池水位計・水門水位計更新工事の発注状況確認**: 農政部 土地改良課へ発注時期を確認。
3. **6月補正予算の確認**: 骨格予算のため、新規事業は補正予算で計上予定。補正後に再調査推奨。
