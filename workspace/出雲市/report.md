# 営業支援レポート: 出雲市 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度一般会計・特別会計予算の概要

## エグゼクティブサマリー（5行以内）

- **消防緊急通信指令施設機器更新事業201,600千円（市債）が最重要案件。** 情報システム・車両動態端末装置の更新整備。消防施設・設備整備全体では336,600千円（市債）。
- **防災対策費80,100千円。** 防災ハザードマップ更新・分散型防災備蓄倉庫整備（コミセン5施設）・非常食料等購入を含む。
- **公共施設長寿命化（道路橋修繕）209,700千円。** 道路橋15橋・歩道橋修繕・修繕設計委託。橋りょう耐震化計画策定（新規）10,000千円も計上。
- 消防自動車等更新事業43,000千円（高規格救急自動車1台・小型ポンプ積載車1台）。
- 市街地水害解消対策事業218,700千円（四絡地区浸水対策工事新規・止水板設置補助新規）。

## 議会・首長の関心（事実ベース）

※ 議事録は今回未収集。予算資料から読み取れる方針のみ記載。

- 一般会計4年連続過去最大。「災害に強い強靭な基盤整備と防災体制の確立」を重点柱の一つとして明示。
- 消防通信指令施設機器更新（201,600千円）が今年度の消防費最大案件。
- 防災対策費に防災ハザードマップ更新・分散型備蓄倉庫整備（コミセン5施設）を計上。
- 橋りょう耐震化計画策定を新規計上。今後の橋梁耐震化投資の計画段階。

## 次アクション提案

1. **【令和8年度内・最優先】消防本部情報指令課への「消防緊急通信指令施設機器更新201,600千円」発注確認**: 大型案件。発注方法・仕様・スケジュールを確認。出雲市消防本部TEL: 0853-21-0119。
2. **【令和8年度内】消防自動車等更新事業43,000千円（救急車1台・積載車1台）の仕様確認**: 警防課へ車種・仕様・発注時期を確認。
3. **【令和8年度内】防災対策費80,100千円の詳細確認**: 防災安全課へハザードマップ更新の発注時期・仕様確認。分散型備蓄倉庫5施設の整備仕様確認。
4. **【継続提案】道路橋修繕・橋りょう耐震化計画**: 建設企画課へ来年度以降の耐震化工事計画の先行確認。
