# 営業支援レポート: 早島町 / 防災
- 作成日: 2026-06-04
- 対象資料: 令和8年度当初予算概要・主要事業説明書（令和8年2月17日）

## エグゼクティブサマリー（5行以内）

- **消防費合計291,372千円（R7比+5,439千円）。常備消防は倉敷市への委託（230,183千円）で直接提案機会は限定的。**
- **消防施設整備事業18,961千円：小型動力ポンプ1基・積載車1台・ホース乾燥塔1基・消火栓工事（3地区4か所）が令和8年度の具体案件。**
- 農業用施設整備事業36,300千円（汐入川排水機場改修・岡山県営土地改良事業負担金）：浸水被害軽減目的。
- 農業用施設保全事業62,333千円（幹線水路浚渫・清掃・暗渠水路堆積調査）：浸水被害軽減目的。
- 一般会計7,721,000千円（R7比△11.7%）。

## 次アクション提案

1. **【令和8年度内】消防施設整備事業の発注状況確認**: 小型動力ポンプ・積載車・ホース乾燥塔・消火栓の各発注先・仕様を早島町消防担当に確認。
2. **倉敷市消防局経由の情報収集**: 常備消防委託先の倉敷市消防局から整備計画・更新予定を確認。

## 要確認事項

- J-ALERT・防災情報システム・ハザードマップ関連事業の有無（主要事業説明書に記載なし）。
- 消防費残余42,228千円（消防団関連費等）の内訳。
- 緊急防災・減災事業債の活用状況（町債総額192,400千円の内訳未確認）。
