# リサーチプラン: 米子市 / 防災

## 1. 調査目的
鳥取県第2の都市・米子市（人口約14万人）の防災関連の予算配分・議会での論点・調達動向を令和7〜8年度を対象に一次情報から把握し、防災システム・物資・耐震化等の領域で新規提案先・調達タイミングを特定する。推測を排し「予算計上・議会答弁・入札公告」という事実に裏打ちされた営業仮説を提供することを目的とする。

## 2. 収集対象（一次情報）
- 予算書:
  - 令和7年度 当初予算（事業別・防災関連款項目）… 現行の重点施策と継続事業の規模把握のため
  - 令和7年度 補正予算（全会期分）… 国の交付金・災害対応・追加調達の動きを捉えるため（補正は新規ニーズの宝庫）
  - 令和8年度 当初予算（公表されていれば）… 次年度の新規・拡充事業を先取りするため。未公表なら「未公表」と明記
- 議会会議録:
  - 令和7年度の全定例会（本会議の一般質問・代表質問）および総務・建設関連の常任委員会
  - 防災・減災に関する質疑、市側の答弁（検討中・予定・課題認識）を抽出。会期は収集役が市議会会議録検索システムで実在確認する
- 入札公告/契約情報:
  - 米子市の入札・契約情報ページ（令和7〜8年度）から防災関連の調達（システム保守・更新、防災行政無線、備蓄、耐震工事等）… 調達サイクルと予算規模の実証のため
- 各項目とも、URL・文書名は収集役が実在確認すること。不明な情報源は創作せず「探索により発見/未発見」を明記する。

## 4. 各エージェントへの指示文（コピペ用）

### → collector-budget
米子市（鳥取県）の防災関連予算を収集してください。対象は令和7年度当初予算、令和7年度補正予算（全会期）、令和8年度当初予算（公表分のみ）。
- 米子市公式サイトの予算書・予算説明資料を出典として、防災に関する事業・款項目・金額を抜き出す。
- 以下の観点を網羅的にチェック（漏れたら「該当記載なし」と明記）:
  地域防災計画/国土強靱化地域計画、治水・河川・浸水対策・土砂災害、建築物/橋梁/上下水道の耐震化、避難所・指定緊急避難場所・福祉避難所、ハザードマップ/防災情報システム/防災行政無線、備蓄/物資/受援計画/BCP、消防・救急/消防団/自主防災組織、防災教育・訓練。
- 米子市特有の論点（独自の防災システム調達、消防本部の体制、境港市など近隣との消防・防災連携の費用負担）に注意して該当予算を探す。
- 各項目に必ず「出典URL・文書名・該当ページ/節」を付す。確認できないものは推測で埋めず「未確認」と記す。自治体名やURLを創作しない。
- 結果を workspace/米子市/budget_raw.md に保存。

### → collector-minutes
米子市議会の令和7年度（定例会・関連常任委員会）の会議録から、防災・減災に関する質疑と市側答弁を収集してください。あわせて米子市の入札・契約情報から令和7〜8年度の防災関連調達公告も収集してください。
- 米子市議会会議録検索システムで「防災」「避難所」「ハザードマップ」「防災行政無線」「耐震」「消防団」「自主防災」「備蓄」「国土強靱化」等を検索し、発言者・年月日・会議名・要旨を出典付きで記録。
- 市側答弁のうち「検討中」「次年度予定」「課題認識」を示す箇所を特に明示（提案機会の手がかり）。
- 入札公告は、案件名・公告日・予定価格/規模・入札方式・落札情報（あれば）をURL付きで記録。防災システム保守更新・防災行政無線・備蓄・耐震工事等を重点に。
- 会期・URL・案件名は実在確認すること。創作禁止。発見できなければ「未発見」と明記。
- 結果を workspace/米子市/minutes_raw.md に保存。

### → analyst-budget
workspace/米子市/budget_raw.md を読み、防災予算を分析してください。
- 第2章の8観点ごとに、事業名・金額・当初/補正の別・新規/継続/拡充を表で整理。
- 令和7→8年度の増減、補正での追加投入を定量的に示し、規模の大きい/動きのある領域を特定。
- 出典が無い数値は分析に使わず「要確認」フラグを付す。事実と推測を分離して記述。
- 結果を workspace/米子市/budget_analysis.md に保存。

### → analyst-needs
workspace/米子市/budget_analysis.md と workspace/米子市/minutes_raw.md を突合し、提案ニーズを抽出してください。
- 「予算計上あり×議会で課題言及あり×調達時期が近い」案件を優先度高として整理。
- 各ニーズに対し、根拠（予算・答弁・入札のどれか）と想定調達時期、提案アングルを記載。
- 米子市独自要素（防災システム、消防本部、近隣連携）に関する機会を明示。
- 推測には「仮説」と明記し、事実と区別。結果を workspace/米子市/needs_analysis.md に保存。

### → qa-editor
needs_analysis.md・budget_analysis.md・各rawを統合し、営業担当向けサマリを作成してください。
- 冒頭にエグゼクティブサマリ（注目領域3〜5点と根拠・時期）。
- 全主張に出典を紐付け、出典なき記述は「推測」と明示。創作された自治体名/URL/金額がないか最終チェック。
- 結果を workspace/米子市/report.md に保存。
