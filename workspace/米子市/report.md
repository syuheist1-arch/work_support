# 営業支援レポート: 米子市 / 防災
- 作成日: 2026-06-02
- 対象資料: 予算（令和6〜8年度当初・補正予算概要、令和6〜7年度随意契約締結状況、国土強靭化地域計画事業一覧）、議事録（総務政策委員会 令和8年2月13日・3月16日）

## エグゼクティブサマリー（5行以内）

- 令和8年1月の島根県東部地震（米子最大震度5弱）と2月大雪孤立が直近のトリガーとなり、避難所運営・備蓄・要配慮者対応の三つの構造的不備が議会で連続して顕在化した。
- 行政自身が「自治連合会への説明が未了」「備蓄は全29公民館中13公民館のみ」「個別避難計画と地域防災が直結していない」と明言しており、課題認識は庁内に形成済みである。
- 防災行政無線（親局更新済）・防災ラジオ（DARAZ随契固定）のハード通信系は既存業者が固定化しており、新規参入余地は薄い。
- 攻め口は「避難所運営・備蓄等の運用・ソフト面」と「要配慮者・共助の仕組み構築」に集中している。
- 令和8年度当初予算（一般会計884億6,000万円）が成立済みで、補正予算・随意契約による追加調達の動きを引き続き注視すべき局面にある。

## 議会・首長の関心（事実ベース）

### 令和8年2月13日 総務政策委員会
出典: https://www.city.yonago.lg.jp/secure/47627/soumuseisakuR080213.pdf

- **山花防災安全課長**: 令和8年1月6日M6.4地震、米子市で最大震度5弱。液状化・建物ひびなど多数被害。市内全29公民館を自主避難所開設、最大39名避難。7,650万円専決。
- **山花防災安全課長**: 「**自治連合会等への説明がまだできていない**」と明言。
- **山花防災安全課長**: 「**備蓄品（水・食料・毛布）を常備するのは土砂災害警戒地区の13公民館のみ（全29中）**」と明言。
- **山花防災安全課長**: 令和8年2月7〜8日の大雪で42センチ積雪。米子市尾高で3世帯6名が孤立、備蓄品の飲料水を配布。
- **安達委員**: 「老健・特養・総合病院等の要配慮者施設からの情報共有が系統立っていたか。情報提供が足りなかった」と指摘。
- **戸田委員**: 「市内30cmだが尾高は60cmと地域格差が相当ある。初動体制を強く要望」。

### 令和8年3月16日 総務政策委員会
出典: https://www.city.yonago.lg.jp/secure/47627/soumuseisakuR080316.pdf

- **田中地域振興課長**: 個別避難計画の累計作成数410件。福祉事業者との協定締結10法人。名簿を全29公民館に配備、協定締結は17地区（全29地区中）。
- **田中地域振興課長**: 「**個別避難計画と地域防災が直結していない**」と明言。
- **岩﨑委員**: 「自治会・消防団・民生委員できちんと共有できているか。福祉事業者が大規模災害時に地域に出向くのは現実問題難しい」と指摘。
- **安達委員**: 「民生委員が選出できない地域・自治会役員の成り手がない」と指摘。

**要配慮者への対応は R8.2.13 と R8.3.16 の2回にわたり複数委員が継続して問題提起（事実）。**
