# 営業支援レポート: 丸亀市 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度予算案大綱・広報誌・建設工事発注見通し

## エグゼクティブサマリー（5行以内）

- 消防費1,526,562千円（前年△50.7%）。前年3,098,906千円は消防庁舎等大型整備があったと推定。
- **【最重要案件】消防団機械器具置場新築（第3分団・第11分団）**。造成工事が発注見通しに掲載済み。
- **災害用備品購入費63,671千円（新規・臨時）・福祉避難所体制整備支援16,800千円（新規）**。備蓄強化と要配慮者避難対応が新規計上。
- **農村地域防災減災事業費14,300千円（新規）**：ため池水位計等観測システム設置工事が発注見通しに掲載。
- 高潮対策（鋼製門扉・堤防嵩上げ）3件・排水ポンプ場整備2件も発注見通しに計上。

## 次アクション提案

1. **消防団機械器具置場新築の発注状況確認**: 消防本部へ第3・第11分団の工事発注時期を確認。
2. **災害用備品の調達内容確認**: 危機管理課へ63,671千円の備品種別・調達スケジュールを確認。
3. **ため池観測システムの工事発注確認**: 農政課へ工事内容・発注時期を確認。

## 要確認事項

- 消防費の項別・目別内訳（前年比△50.7%の要因となった前年度大型事業の内容）
- 消防車両・防火水槽等整備の令和8年度計画
- 消防通信・無線関連の調達計画
