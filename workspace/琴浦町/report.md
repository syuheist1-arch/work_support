# 営業支援レポート: 琴浦町 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度当初予算 事業説明書（総務課・建設住宅課）

## エグゼクティブサマリー（5行以内）

- 一般会計148億5,300万円（過去最大・R7比+12.8%）。消防費652,899千円のうち非常備消防費が前年比+255,214千円と大幅増だが、東桜ヶ丘ブロック塀撤去新設事業268,518千円（基金繰入）が大部分を占める。
- **消防ポンプ自動車購入事業36,395千円（新規）**は導入20年以上の消防ポンプ自動車1台更新（第7分団赤碕・緊急防災・減災事業債34,700千円）。今年度の最重要直接案件。
- 防災行政無線は保守点検・修繕のみ（7,962千円）。新規整備なし。ただしR7繰越の「情報通信基盤改修事業59,400千円」の内容が未確認—要追跡。
- 浸水被害防止対策事業56,800千円（建設住宅課・緊急自然災害防止対策事業債）が令和3年豪雨被害地区で継続中。農林水産課分48,522千円は未確認。
- 橋梁修繕関係が集中計上：三本杉橋梁修繕30,000千円・大父橋梁修繕20,000千円・田越橋梁修繕20,000千円ほか計115,000千円規模。

## 議会・首長の関心（事実ベース）

※ 議事録は今回未収集。予算資料から読み取れる方針のみ記載。

- 過去最大予算規模。浸水被害防止対策・橋梁修繕・水路改修等のインフラ防災投資を大量計上。
- 消防ポンプ自動車を新規計上し、緊急防災・減災事業債を積極活用。
- 自主防災組織育成（コミュニティ助成事業・2団体）とハザードマップ新規作成で地域防災力向上を推進。
- R7年度繰越「情報通信基盤改修事業59,400千円」の内容が要確認—防災無線系更新の可能性あり。

## 次アクション提案

1. **【最優先・令和8年度内】総務課への消防ポンプ自動車購入事業確認**: 36,395千円・1台の発注仕様・時期・入札方法を即確認。緊急防災・減災事業債充当案件。琴浦町役場TEL: 0858-52-1703（代表）。
2. **【緊急確認】情報通信基盤改修事業59,400千円（R7繰越）の内容確認**: 防災行政無線の更新工事の可能性。繰越事業のため早期に発注される可能性が高い。
3. **【令和8年度内】建設住宅課への橋梁修繕・水路改修発注確認**: 橋梁5件合計約115,000千円＋赤碕水路改修50,000千円。発注時期・対象箇所の仕様を確認し入札参加準備。
4. **【情報収集】農林水産課の浸水被害防止対策事業48,522千円の内容確認**: 建設住宅課分56,800千円に加えて農林水産課分があり、合計規模105,322千円。
5. **【並行】鳥取中部ふるさと広域連合への接触**: 三朝・湯梨浜・琴浦3町共通の広域連合。常備消防費・庁舎建設の動向を横断的に把握。
