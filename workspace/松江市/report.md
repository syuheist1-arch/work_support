# 営業支援レポート: 松江市 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度一般会計予算概要・予算説明書

## エグゼクティブサマリー（5行以内）

- **消防車両整備事業2億7,440万円（市債2億7,300万円）が最重要案件。** 水槽車・ポンプ車・救急車・軽積載車5台の4種類を計画的更新。うち水槽車1億400万円（債務負担行為・R10.3納車）・北部1警防隊車8,000万円（繰越明許）は来年度以降の契約対象。
- **消防救急デジタル無線再整備事業費1,200万円。** 消防救急デジタル無線の更新整備。
- 避難所指定学校体育館への空調整備事業1億854万円（R8：第三中学校）。R6〜15年度で16校整備計画中。
- 防災対策費7,035万円（R7比△65,346万円・大型整備の反動減）。防災資機材整備1,027万円・防災対策関連機器維持管理費4,542万円が継続計上。
- 竹矢公民館建て替え2億9,923万円（避難所機能・非常用電源・防災備蓄倉庫新設含む）が継続実施中。

## 議会・首長の関心（事実ベース）

※ 議事録は今回未収集。予算資料から読み取れる方針のみ記載。

- 令和7年度の大雨・地震災害復旧（112億円余の補正予算）への対応が明記されており、防災・減災への高い意識。
- 消防車両の計画的整備を主要事業として明示。「高まる市民の防災需要に対応」と説明。
- 避難所指定学校体育館への空調整備をR6〜15年度計画として推進。
- 水道・下水道事業で「地域防災力の強化のため施設・設備の耐震化、雨水排水対策を推進」と明記。

## 次アクション提案

1. **【令和8年度内・最優先】消防本部への消防車両整備事業発注確認**: 南救急2号車4,690万円（R9.3納車）・軽積載車5台4,350万円（R9.3）は令和8年度中に発注。水槽車・ポンプ車は債務負担・繰越明許で発注時期が異なる。消防本部消防総務課・警防課へ発注スケジュール確認。松江市消防本部TEL: 0852-24-9969。
2. **【令和8年度内】消防救急デジタル無線再整備1,200万円の仕様確認**: 更新機器の仕様・発注方法（随意・入札）を確認。
3. **【令和8年度内】避難所空調整備（第三中学校）の施工業者確認**: 工事費9,830万円（設計はR7済み）の発注時期・入札参加条件を確認。教育委員会教育総務課へ。
4. **【継続提案】避難所空調整備の今後計画確認**: R9〜15年度に残り14校整備予定。次年度以降の発注候補を先行確認。
