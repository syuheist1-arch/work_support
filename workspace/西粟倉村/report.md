# 営業支援レポート: 西粟倉村 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度当初予算書（令和8年3月5日議決）

## エグゼクティブサマリー（5行以内）

- 消防費91,393千円（前年比+3,507千円）。一般会計規模の小さい村だが防災投資に積極的。
- **【最重要案件】避難所環境整備・防災力向上事業11,324千円**。具体的な機器・設備調達の可能性あり。
- **ハザードマップ更新事業2,910千円**（業務委託の可能性）。GIS・測量・印刷関連。
- **緊急自然災害防止対策事業42,000千円（地方債42,000千円）**が土木費・林業費に計上。
- J-ALERT維持管理・防災行政無線・ドローン防災活用事業も継続計上。

## 次アクション提案

1. **避難所環境整備・防災力向上事業の内容確認**: 総務課へ設備・機器の仕様・調達方法を確認。11,324千円の大型案件。
2. **ハザードマップ更新事業の発注状況確認**: 業務委託なら参加機会あり。仕様・入札スケジュールを確認。
3. **緊急自然災害防止対策事業の工事内容確認**: 建設担当へ工事概要・発注スケジュールを問い合わせ。

## 要確認事項

- 避難所環境整備・防災力向上事業の具体的内容（設備種別・数量）
- ハザードマップ更新事業の業務委託先・仕様
- 緊急自然災害防止対策事業42,000千円の工事内容
