# 営業支援レポート: 美郷町 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度当初予算の概要

## エグゼクティブサマリー（5行以内）

- **耐震型防火水槽設置事業12,350千円（緊急防災・減災事業債12,300千円）が最重要案件。** 別府地域小松地地内1箇所に設置。工事発注が近い。
- **消防団小型ポンプ積載車更新事業10,907千円（緊急防災・減災事業債8,300千円）。** 軽積載車1台更新。車両調達案件。
- **地区防災計画作成支援業務17,028千円（国費・地域福祉振興基金8,500千円）。** 吾郷・別府の2地区に専門家派遣・防災士育成等。委託業務。
- 江津邑智消防組合施設改修負担金10,092千円（緊急防災・減災事業債10,000千円）。広域組合の施設改修への参加分担。
- 消防費合計329,773千円（R7比△4.1%）。R7に比べ大型整備がなく減少。起債対象の主要3事業で緊急防災・減災事業債20,600千円活用。

2. **【令和8年度内】消防担当への耐震型防火水槽設置（12,350千円）工事発注確認**: 緊急防災・減災事業債12,300千円充当。施工業者選定方法・入札条件を確認。
