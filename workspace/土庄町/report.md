# 営業支援レポート: 土庄町 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度当初予算概要広報紙・施政方針

## エグゼクティブサマリー（5行以内）

- 一般会計100億9,300万円（前年比△6.1%）。消防費4億364万円（歳出比4.0%）。
- **【最重要案件】防災・減災対策強化事業群1億6,459万円**（中小川防災ハザードマップ作成・コンテナトイレ設置・地域防災力強化等を含む）。
- **小海漁港・田井漁港 護岸改修工事（高潮対策）・唐櫃漁港 護岸耐震化・津波浸水対策**が施政方針に記載。
- 町内各所ポンプ場の長寿命化・大谷ポンプ場幹線整備（継続）が計上。
- 消防費項別・目別詳細は企画財政課への直接確認が必要。

## 次アクション提案

1. **防災・減災対策事業群の内訳確認**: 企画財政課（0879-62-7014）へ1億6,459万円の内訳・発注スケジュールを確認。
2. **漁港護岸改修・耐震化工事の発注確認**: 建設課へ小海・田井・唐櫃漁港の工事発注時期を確認。
3. **消防費内訳の確認**: 消防施設整備（車両・防火水槽等）の令和8年度計画を確認。

## 要確認事項

- 消防費403,640千円の項別・目別内訳（消防施設整備・車両等の個別金額）
- 防災・減災対策事業群164,590千円の個別事業金額と発注時期
- 漁港護岸工事の工事費・発注スケジュール
