# 営業支援レポート: 善通寺市 / 防災
- 作成日: 2026-06-12（2026-06-05作成→更新）
- 対象資料: 令和8年度一般会計予算のポイント・施政方針・款別予算一覧

## エグゼクティブサマリー（5行以内）

- 消防費528,724千円（前年比+26,635千円、**+5.3%増**）。一般会計総額15,643,000千円（+1.3%）。
- **【最重要案件】消防車両及び資機材の計画的整備更新**（施政方針に明記）。消防体制強化を重点方針に位置付け。
- **シェルターテント整備（新規）・避難所開設訓練強化・感震ブレーカー補助新設**が令和8年度新規施策。
- 地域防災リーダー育成事業・家具転倒防止対策事業も継続計上。
- 消防費の項・目別内訳は予算書本体（未公開）のため消防本部への直接確認が必要。

## 次アクション提案

1. **消防車両整備の仕様・スケジュール確認**: 消防本部へ令和8年度更新予定の車種・仕様・発注時期を確認（+5.3%増の主因）。
2. **シェルターテント等新規備品の調達確認**: 自治防災課へ種別・数量・発注スケジュールを確認。
3. **感震ブレーカー補助の詳細確認**: 補助対象・補助率・台数規模を確認。

## 要確認事項

- 消防費528,724千円の項別・目別内訳（消防施設費・車両整備等の個別金額）
- 消防車両更新の対象車種・台数・発注時期
- シェルターテント・感震ブレーカー補助の調達規模と発注スケジュール
