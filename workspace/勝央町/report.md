# 営業支援レポート: 勝央町 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度当初予算（広報しょうおう令和8年4月号）

## エグゼクティブサマリー（5行以内）

- 一般会計68億2,000万円（+2,000万円）。消防費の詳細は予算書PDF未公開のため不明。
- **【最重要案件】勝央中学校体育館への空調設備設置**（避難所機能強化目的・国補助活用・令和8年度設計→令和9年度設置）。設計業務の発注が令和8年度内に見込まれる。
- 水道耐震化工事の財源確保が急務との施政方針記述あり。水道事業会計6億1,919万円（+5.4%）。
- 勝央町は津山圏域消防組合（6市町）に加入。消防費の大半は消防組合負担金と推定される。
- 消防費の個別金額は予算書PDF未公開のため要役場確認。

1. **中学校体育館空調設計業務の発注状況確認**: 教育振興部へ設計業務の仕様・発注スケジュールを問い合わせ。
