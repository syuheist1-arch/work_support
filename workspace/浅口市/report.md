# 営業支援レポート: 浅口市 / 防災
- 作成日: 2026-06-04
- 対象資料: 令和8年度当初予算の概要（令和8年3月）

## エグゼクティブサマリー（5行以内）

- **骨格予算（市長・市議会議員選挙年度）のため政策的経費は6月補正に計上予定。**
- **倉敷市常備消防負担金76,366千円（新規）：玉島消防署西出張所の耐震補強・長寿命化工事負担金。令和8年度内の工事案件。**
- 消防費合計883,605千円（一般会計の5.6%）。常備消防は笠岡地区消防組合（寄島・鴨方）と倉敷市（金光）の2系統に委託。
- 災害対策事業130,414千円（農林施設災害対策32,100・公共施設災害対策70,725・備蓄品2,540）。
- 非常備消防施設整備事業50,025千円（消防団施設・機材整備・修理）。

## 次アクション提案

1. **【6月補正後・最優先】政策的経費の追加案件確認**: 骨格予算のため、6月補正予算で防災・消防関連の追加計上が見込まれる。補正予算成立後（6月議会後）に財政課または消防担当に確認。
2. **玉島消防署西出張所耐震補強の工事発注状況確認**: 倉敷市側の発注先・工事仕様を把握し、関連設備・機器の提案機会を探る。
3. **笠岡地区消防組合への整備計画確認**: 組合の令和8〜9年度の消防施設・車両整備計画を直接確認。

## 要確認事項

- 6月補正予算での防災・消防関連追加事業の内容（骨格予算のため未計上分あり）。
- 笠岡地区消防組合424,243千円の内訳（車両・機器更新等）。
- 消防費前年比の詳細（前年度骨格予算との比較で実態が見えにくい）。
