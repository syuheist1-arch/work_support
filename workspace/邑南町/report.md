# 営業支援レポート: 邑南町 / 防災
- 作成日: 2026-06-04
- 対象資料: 令和8年度当初予算

## エグゼクティブサマリー（5行以内）

- **消防積載車更新（石見地域第10・第11分団）が最重要案件。** 消防債3,430万円を江津邑智消防組合庁舎改修+消防積載車更新に充当。車両2台更新の案件。
- **消防費合計4億9,820万9千円（R7比+284万6千円）。** 常備消防費3億9,610万7千円（江津邑智消防組合負担金）・非常備7,107万2千円・消防設備費2,504万1千円。
- **おおなんケーブルテレビ放送設備複線化（電気通信事業特別会計3億9,400万円）。** 施政方針に「災害時に確実・安定的な情報伝達維持のため放送設備の複線化を実施」と明記。
- 消防設備費内に消防団デジタル無線機追加配備（国庫補助金30万4千円）。個別避難計画作成事業費・防災備蓄品整備を防災費598万9千円で継続。
- 一般会計135億5,800万円（R7比△0.8%）。消防費は微増で維持。
