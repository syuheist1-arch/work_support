# 営業支援レポート: 岩美町 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度当初予算構成表・予算審査特別委員会報告書・議会だよりNo.167

## エグゼクティブサマリー（5行以内）

- 消防費が315,126千円（R7比+18.7%）、土木費が745,494千円（R7比+31.7%）と両款とも大幅増。ただし事業別明細書は非公開のため内訳の詳細は未確認。
- 防災行政無線の新規整備・更新に関する記載は予算書・議会資料・入札公告いずれにもなし。現状は保守点検のみと推定されるが公式確認不可。
- 家庭用防災用品購入補助金150万円が新規計上。自主防災組織活動費補助金はR7〜R11年度計画で資機材整備を継続支援。
- 指定避難所である小学校体育館の空調整備を検討中（R8年度は調査・検討段階）。着手が決定すれば提案機会あり。
- 消防費増加（+4,973万円）・土木費増加（+17,962万円）の内訳が非公開のため、攻めどころの確度は全般的に低い。個別事業の確認には担当課への直接接触が必要。

## 議会・首長の関心（事実ベース）

- 令和8年度予算編成方針に「防災・減災・国土強靭化を重要政策課題として位置づけ」と明記。「第11次岩美町総合計画」の中間年度として防災・減災対策を列挙。
- 田後・網代のコミュニティ消防センター・防災センターの指定管理者をR8年度から地区自治会（10年間）に移行。
- 小学校体育館（指定避難所）の空調整備を検討中。R8は調査段階。

## 次アクション提案

1. **【最優先・令和8年度内】総務課（防災担当）への直接接触**: 消防費増加分（+4,973万円）・土木費増加分（+17,962万円）の内訳は非公開。「令和8年度の消防・防災関連で新規発注予定の工事・委託があれば情報提供を」の切り口で接触。岩美町役場TEL: 0857-72-0321（代表）。
2. **【令和8年度内】建設課への土木費内訳確認**: 土木費+31.7%増の内訳（道路・河川・防災工事）を直接確認し提案機会を特定。
3. **【仕込み】小学校体育館 空調整備の進捗確認**: 教育委員会に整備方針・スケジュールを確認。整備着手決定時に即応できる体制を整える。
4. **【並行】入札公告の定期確認**: 岩美町入札情報（https://www.iwami.gr.jp/3061.htm）で防災・消防・土木系案件が出たら即対応。
