# 営業支援レポート: 久米南町 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度当初予算資料（r08_yosansiryou.pdf）

## エグゼクティブサマリー（5行以内）

- 一般会計57億3,000万円（前年比+23.3%）。消防費114,886千円（+2.3%）。
- **【最重要案件】橋梁の防災対策事業60,500千円（継続）・町道の防災対策事業34,000千円（継続）**。土木費内に大型防災対策事業が2件継続中。
- **消防団員新基準活動服3,700千円（新規）**が令和8年度の新規調達案件として確認。
- 防災行政無線管理費10,640千円が継続計上。保守委託の入札機会あり。
- 勝央町・奈義町・鏡野町・久米南町・美咲町などとともに津山圏域消防組合（常備消防負担金75,320千円）に加入。

## 次アクション提案

1. **橋梁・町道防災対策事業の発注状況確認**: 建設課へ工事発注スケジュール・仕様を確認。継続事業のため発注先が固定化している可能性あり。
2. **消防団員新基準活動服の調達確認**: 総務課へ調達方法・数量・仕様を確認。令和8年度新規事業。
3. **防災行政無線保守委託の入札情報確認**: 総務課または入札情報システムで保守委託の入札状況を確認。

## 要確認事項

- 橋梁・町道防災対策事業の工事概要・発注先
- 消防施設整備（車両・ポンプ等）の令和8年度計画（予算書本体は403で取得不可）
- 債務負担行為の防災・消防関連分
- 発注見通し（404で取得不可: https://www.town.kumenan.lg.jp/）
