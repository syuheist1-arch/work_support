# 営業支援レポート: 吉備中央町 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度当初予算のあらまし

## エグゼクティブサマリー（5行以内）

- 一般会計102億9,000万円（前年比△17.9%）。消防費513,381千円（前年比+47,331千円、**+10.2%大幅増**）。
- **【最重要案件】消防費が前年比+10.2%の大幅増**。増加要因の詳細（車両更新・施設整備等）は予算書本体で要確認。
- 農業水路等長寿命化・防災減災事業26,750千円が農林水産業費に計上。
- 災害復旧費17,572千円（農地8,541千円＋土木9,031千円）が計上。
- 消防施設整備負担金交付事業（事業費2/3・上限100万円）により自治会等への補助実績あり。
