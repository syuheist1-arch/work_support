# 営業支援レポート: 観音寺市 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度当初予算書（令和8年第1回定例会提出議案）

## エグゼクティブサマリー（5行以内）

- 消防費287,217千円（前年比+40,550千円、**+16.4%大幅増**）。
- **【最重要案件】消防ポンプ車整備事業29,205千円（地方債29,200千円・債務負担R8-R9計31,738千円）**。
- **消防屯所建設事業11,515千円（地方債11,500千円）**。新設・建替の消防屯所整備案件。
- **地震・津波対策海岸堤防等整備事業57,200千円・市道橋落橋防止対策202,900千円**が土木費に計上。
- 防災重点農業用ため池緊急整備事業12,000千円（補助）も計上。

## 次アクション提案

1. **消防ポンプ車の仕様・発注確認**: 消防本部へ車種・仕様・発注スケジュールを確認。
2. **消防屯所建設事業の場所・設計確認**: 新設場所・工事発注時期を確認。

## 要確認事項

- 消防ポンプ車の車種・台数・発注時期
- 消防屯所建設の場所・規模・工事発注時期
- 消防費目別内訳（消防活動費・消防施設費等）
