# 営業支援レポート: 雲南市 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度当初予算概要・予算書

## エグゼクティブサマリー（5行以内）

- **消防機器整備事業47,536千円（緊急防災・減災事業債42,400千円）が最重要案件。** R7比+7.6%増。消防団向け機器整備（具体的内容は要確認）。
- **デジタル防災行政無線管理事業38,776千円（R7比+101.3%・約2倍増）。** 屋外スピーカーバッテリー交換等。原子力防災基金繰入金36,571千円を財源充当。
- **原子力災害対策事業17,587千円（原子力防災基金充当）。** 島根原発立地市として原子力防災体制を継続整備。
- 菅谷たたら山内防災整備事業47,220千円（R7比+38,180千円・新規拡充）。防災施設（消火設備）の新設工事。文化財防火対策の大型案件。
- 雲南広域連合消防分負担金766,696千円（R7比+37,018千円）。常備消防は広域組合。

## 次アクション提案

1. **【令和8年度内・最優先】消防機器整備事業（47,536千円）の具体的内容確認**: 緊急防災・減災事業債42,400千円充当。車両・機器の種類・仕様・発注時期を防災部消防担当へ確認。雲南市TEL: 0854-40-1020。
2. **【令和8年度内】デジタル防災行政無線管理事業（38,776千円）の発注内容確認**: 屋外スピーカーバッテリー交換等の仕様・発注先を危機管理担当へ確認。
3. **【情報収集】西日登分団機庫建設設計（1,000千円）**: 設計完了後の本体工事（翌年度）に向けた先行アプローチ。
4. **【継続提案】雲南広域連合消防への提案**: 負担金最大項目の雲南広域連合（消防）への機器・設備提案機会を把握。
