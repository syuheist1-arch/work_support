# 営業支援レポート: 高松市 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度当初予算の概要（令和8年2月）

## エグゼクティブサマリー（5行以内）

- 一般会計1,928億円。消防費5,885,862千円（前年比+6.7%、+370,263千円）と大幅増加。
- **【最重要案件】消防車両整備事業355,816千円**：ポンプ車・高規格救急自動車・ドローン・AED更新等。牟礼分署・香川分署・塩江出張所が対象。
- **北消防署再整備事業（新規・81,063千円）**：基本設計・地質調査・駐車場解体実施設計。令和9年度債務負担9,147千円あり。
- **小中学校体育館空調設置（避難所機能向上・182,652千円）**：債務負担R9-R26年度 7,992,055千円の大型事業。古高松・古高松南小を先行整備。
- 地震・津波海岸堤防等対策事業500,830千円・住宅耐震改修拡充164,521千円・南海トラフ地震等総合対策32,327千円（防災DX新規）も計上。

## 次アクション提案

1. **消防車両更新仕様確認**: 消防局総務課（087-861-2502）へ355,816千円の発注スケジュール・各車種の仕様を確認。
2. **北消防署再整備事業の入札情報確認**: 基本設計・地質調査の設計業者選定状況を確認。
3. **小中学校体育館空調の工事発注計画確認**: 教育局総務課 学校施設整備室へR8年度先行整備2校の発注スケジュールを確認。

- 北消防署再整備事業の設計業者選定時期
