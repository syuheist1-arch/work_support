# 営業支援レポート: 井原市 / 防災
- 作成日: 2026-06-04
- 対象資料: 令和8年度当初予算編成概要（議会修正可決後）

## エグゼクティブサマリー（5行以内）

- **井原地区消防組合 高機能消防通信指令システム・デジタル無線更新整備負担金358,963千円（R8〜R9）が最重要案件。R8:通信指令システム、R9:デジタル無線の順で整備。**
- 消防費合計1,264,195千円（前年比+46.3%・+400,180千円）。指令システム更新が主因で大幅増。
- 防災マップ更新事業7,562千円（南海トラフ見直し・高屋川浸水想定反映）。
- 災害時備蓄食糧等整備2,650千円（南海トラフ地震目標備蓄量確保）・ため池監視システム3,261千円（3池・新規）。
- 一般会計総額26,099,000千円（R7比+0.7%・過去最大）。

## 次アクション提案

1. **【情報収集・最優先】井原地区消防組合への通信指令システム更新状況確認**: 令和8年度発注予定か否か、機器仕様・メーカー選定状況を確認。
2. **【R9準備】消防救急デジタル無線更新の仕様情報収集**: 令和9年度実施予定。今から仕様策定に関与するためのアプローチ。
3. **【令和8年度内】防災マップ更新（7,562千円）の委託先・公告状況確認**: 危機管理担当へ問い合わせ。

- 消防費内訳（常備消防費・非常備消防費・消防施設費等）の詳細。
