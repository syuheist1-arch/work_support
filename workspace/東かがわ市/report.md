# 営業支援レポート: 東かがわ市 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度予算書（取得不可）/ 令和2年度決算（参考）

## エグゼクティブサマリー（5行以内）

- **東かがわ市公式サイトはSMART CMSのJSレンダリングのため、令和8年度予算書PDFを直接取得できず。**
- 令和2年度決算では消防費596,177千円。大川広域行政組合に常備消防を委託。
- 消防施設整備（屯所建替含む）・地域防災無線維持管理・自主防災組織支援が令和2年度に計上。
- 令和8年度の具体的案件は役場への直接確認が必要。

## 次アクション提案

1. **東かがわ市役場 財政課・危機管理課に直接問い合わせ**: TEL 0879-26-1234。令和8年度当初予算書（消防費・防災費の内訳）の入手または閲覧を依頼。
2. **大川広域行政組合**への消防施設整備計画の確認。
