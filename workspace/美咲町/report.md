# 営業支援レポート: 美咲町 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度一般会計当初予算書（議案第29号）

## エグゼクティブサマリー（5行以内）

- 一般会計107億1,588万円（前年比△5.4%）。消防費324,485千円（前年比△9,678千円）。
- **【最重要案件】消防自動車整備事業（消防設備整備事業債12,300千円）**。消防車輌等臨時管理費12,846千円が計上されており、令和8年度に消防車両更新が予定されている。
- **防火水槽整備事業15,731千円（消防施設整備事業債15,400千円）**。新設防火水槽の整備案件。
- **道路防災対策事業94,300千円（前年度比+44,300千円・大幅増）**・農業施設防災対策事業120,000千円が土木費・農林水産業費に計上。
- 緊急自然災害防止対策事業債の残高1,043,816千円・令和8年度新規起債180,400千円と防災インフラ整備が旺盛。

## 次アクション提案

1. **消防自動車の更新仕様確認**: 総務課（消防担当）へ更新車両の種類・仕様・発注スケジュールを確認。
2. **防火水槽整備事業の場所・仕様確認**: 新設場所・工事発注スケジュールを確認。
3. **道路防災対策事業の発注状況確認**: 建設課へ94,300千円の事業内容・発注スケジュールを確認。

## 要確認事項

- 消防自動車整備の更新車両種別（消防ポンプ車/タンク車等）
- 防火水槽整備の設置場所・容量
- 道路防災対策事業の具体的工事内容
