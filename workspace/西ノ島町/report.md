# 営業支援レポート: 西ノ島町 / 防災
- 作成日: 2026-06-04
- 対象資料: 令和8年度当初予算（広報西ノ島4月号）

## エグゼクティブサマリー（5行以内）

- **消防ポンプ車更新38,000千円が最重要案件。** 普通建設事業費に計上。R8予算化済みの車両更新案件。
- **隠岐広域連合負担金（令和7年度：消防通信指令デジタル無線整備・島前分署整備 637,552千円）が大幅減。** R8は消防庁舎建設完了により大幅減となり、一般会計が△10.5%の主因。次の大型投資把握が重要。
- 消防費の款別詳細は広報誌資料では未確認。防災行政無線・備蓄等の詳細も未確認。
- 一般会計712,232千万円（R7比△10.5%）。消防庁舎建設の大型整備が終了し縮小。
- 今後の消防施設整備はR9以降に復活する可能性。隠岐広域連合への情報収集が重要。

## 議会・首長の関心（事実ベース）

- 消防庁舎建設（隠岐広域連合）が完了。「消防庁舎建設に係る隠岐広域連合負担金が大きく減となったため、一般会計の予算規模は前年度比-10.5%と大幅な減」と広報誌に明記。
- 国土強靭化実施中期計画に基づく防災・減災インフラ整備を継続推進と記載。

## 次アクション提案

1. **【令和8年度内・最優先】消防担当課への消防ポンプ車更新（38,000千円）の仕様・入札確認**: 広報誌記載の車両更新案件。仕様・発注時期・入札条件を確認。西ノ島町役場TEL: 08514-6-0111。
2. **【仕込み】隠岐広域連合への次期整備計画確認**: 消防庁舎・無線整備完了後の次の計画（R9以降の車両・設備更新等）を把握。
