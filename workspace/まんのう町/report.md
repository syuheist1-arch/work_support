# 営業支援レポート: まんのう町 / 防災
- 作成日: 2026-06-11
- 対象資料: 令和8年度当初予算（広報まんのう令和8年5月号）

## エグゼクティブサマリー（5行以内）

- 消防費674,127千円（歳出比5.6%）。一般会計全体は△5.2%減の中、消防費は前年並みを維持。
- 消防費の項・目別内訳は広報誌では非公開。詳細は役場総務課への直接確認が必要。
- 令和7年度に**ため池水位監視システム設置工事（亀越池他2地区、約693万円）**を発注実績あり。令和8年度も類似案件の可能性。
- 農林水産業費9億779.2万円（7.5%）に防災関連事業が含まれる可能性。

## 次アクション提案

1. **まんのう町役場 総務課に直接問い合わせ**（Tel: 0877-73-0100）: 消防費674,127千円の内訳（消防施設整備・車両更新等）を確認。
2. **令和8年度ため池防災案件の確認**: 産業振興課へ令和8年度のため池水位監視システム設置等の計画を確認。
