# 営業支援レポート: 境港市 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度当初予算概要（緑本）・消防費/総務費/土木費全事業一覧PDF

## エグゼクティブサマリー（5行以内）

- 市の防災行政無線（同報系）はR2年度末に更新完了済み。R8は保守管理のみ（8,771千円）。無線本体更新の提案機会なし。
- 鳥取県防災行政無線（衛星系）の施設更新事業が開始。境港市の負担金1,197千円が新規計上。県主導の案件で規模の把握には県へのアプローチが必要。
- 避難所等環境整備事業が2,151→9,370千円（約4.4倍増）、防災連携備蓄整備事業が501→2,399千円（約4.8倍増）と備蓄・避難所整備に大幅増。地域未来交付金（地域防災緊急整備型）を活用。
- 消防施設管理事業でR8から緊急防災・減災事業債（3,500千円）を初活用し消火栓整備を開始。消防水利充足率77.5%（県内平均92.0%）を補う計画で、R12年度期限までの集中整備方針あり。
- 安全・安心な道づくり事業（橋梁・舗装老朽化対策）が161,026千円（R7比+34,517千円）に増額。防災危機管理課・建築営繕課が主な提案窓口。

## 議会・首長の関心（事実ベース）

※ 議事録は今回未収集。予算概要から読み取れる方針のみ記載。

- 予算概要p1-2に「令和8年1月6日発生の島根県東部を震源とする地震や大雪など頻発する自然災害等の教訓を踏まえ、事前防災と事後防災の二段構えによる『災害に強い環境づくり』を重点項目とした」と明記。
- 消防施設管理事業で「R8から優先箇所を整備するよう方針を見直し」と記載。R9以降の具体的整備計画を策定し緊急防災・減災事業債期限（R12）までに集中整備する方針を明示。
- 避難所等環境整備事業・防災連携備蓄整備事業をいずれも大幅増額し、地域未来交付金を活用。

## 次アクション提案

1. **【最優先・令和8年度内】防災危機管理課への消火栓整備アプローチ**: R8から優先箇所整備開始。「消防水利充足率改善のための消火栓整備計画と発注時期を確認させてほしい」の切り口で接触。境港市役所TEL: 0859-44-1111（代表）。
2. **【令和8年度内】避難所等環境整備・備蓄品の調達確認**: 9,370千円・2,399千円の具体的調達品目・発注時期を確認。資機材・備蓄品メーカーとして提案機会を探る。
3. **【仕込み・R8〜12年度】消火栓整備の継続受注計画確認**: R9以降の整備計画策定を把握し、緊急防災・減災事業債期限（R12）までの複数年受注を視野に入れた提案。
4. **【情報収集】鳥取県防災行政無線（衛星系）更新の総事業規模確認**: 市負担金1,197千円のみが判明。県側の発注規模・スケジュールを鳥取県危機管理局に確認。
5. **【並行】入札公告の定期確認**: 境港市入札公告を定期チェックし、消火栓整備・避難所資機材の案件が出たら即応。
