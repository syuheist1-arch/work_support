# 営業支援レポート: 和気町 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度当初予算（取得不可）/ 令和5年度決算（参考）

## エグゼクティブサマリー（5行以内）

- **和気町公式サイトはSMART CMSのJSレンダリングのため、令和8年度予算書PDFを直接取得できず。**
- 令和5年度決算では消防費376,639千円（歳出全体の3.9%）。令和8年度は役場への直接確認が必要。
- 令和5年度決算で普通建設事業費2,029,893千円と大規模な投資的経費が確認されており、防災関連工事の可能性がある。
- 役場への直接問い合わせ（財政担当: 0869-93-3682）が最優先。

## 次アクション提案

1. **和気町役場 財政課に直接問い合わせ**: TEL 0869-93-3682。令和8年度当初予算書（消防費・防災費の款別内訳）の入手または閲覧を依頼。
2. **公式サイト予算ページの再確認**: https://www.town.wake.lg.jp/soshiki/zaisei/ で令和8年度予算書PDFが公開されているか確認。
