# 営業支援レポート: 美作市 / 防災
- 作成日: 2026-06-04
- 対象資料: 令和8年度当初予算概要（骨格予算）

## エグゼクティブサマリー（5行以内）

- **骨格予算のため政策的経費は6月補正予算で追加計上予定。消防自動車整備事業81,200千円（消防自動車購入費の増）が令和8年度最大の消防設備案件。**
- **防災公園整備事業230,942千円（緊防債229,300千円）が継続中。美作市総合防災施設整備条例に基づく大型事業。**
- 消防費合計948,173千円（R7比+7.0%・+62,251千円）。増加要因は消防自動車購入費の増。
- 防災・安全交付金事業236,800千円（道路防災対策工事・橋梁点検修繕）。
- 消防救急デジタル無線負担金事業14,747千円・通信指令業務共同運用事業15,752千円を計上。

## 次アクション提案

1. **【最優先】消防自動車整備事業の発注状況確認**: 既発注か否か消防本部に確認。緊急消防援助隊設備整備費補助金（15,029千円）を活用していることも踏まえた提案。
2. **【6月補正後】政策的経費の追加案件確認**: 骨格予算のため、6月補正予算で防災・消防関連の追加計上が見込まれる。補正予算成立後に再調査。
3. **防災公園整備事業の工事内容確認**: 令和8年度の防災公園整備に関連する設備・機器の調達状況を危機管理担当に確認。

## 要確認事項

- 消防自動車整備事業の発注先・仕様・車種（消防ポンプ車・救急車等）。
- 通信指令業務の共同運用先（津山圏域消防組合か別の広域組合か）。
- 骨格予算のため、6月補正予算での防災・消防関連追加事業の内容。
- 地域ICT利活用事業20,350千円（消防費計上）の具体的内容。
