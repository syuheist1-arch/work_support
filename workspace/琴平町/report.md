# 営業支援レポート: 琴平町 / 防災
- 作成日: 2026-06-10
- 対象資料: 令和8年度当初予算関係資料

## エグゼクティブサマリー（5行以内）

- 消防費315,837千円（前年比△9,030千円、**△2.8%減**）。内訳（項・目レベル）は概要資料に非公開。
- 一般会計総額7,212,970千円（+12.8%増）と大幅増の中、消防費は微減。
- **砂防維持修繕費23,000千円**（地方債充当）・災害対策管理費2,992千円が投資的事業として計上。
- 消防費315,837千円の内訳（消防施設整備・車両等）は役場への直接確認が必要。

## 次アクション提案

1. **琴平町役場 総務課（消防担当）に直接問い合わせ**: 消防費315,837千円の内訳（消防施設費・消防車両等）を確認。
2. **砂防維持修繕費23,000千円の発注確認**: 工事内容・発注スケジュールを建設課に確認。
