# 営業支援レポート: 直島町 / 防災
- 作成日: 2026-06-10
- 対象資料: 令和6年度予算（広報紙）※令和8年度予算取得不可

## エグゼクティブサマリー（5行以内）

- **令和8年度当初予算書取得不可**。町公式サイトがJSレンダリングのためPDFリンク取得不可。
- 令和6年度参考値: 第1分団屯所更新事業 約2億8,000万円（継続事業）が最大案件。
- 直島町には常備消防機関なし。消防団が消火・予防・救助を担当（志願制）。
- 令和8年度防災予算の詳細把握には役場総務課への直接問い合わせが不可欠。

## 次アクション提案

1. **直島町役場 総務課に直接問い合わせ**: 令和8年度消防費・防災費の予算内訳と消防団設備更新計画を確認。
2. **第1分団屯所更新事業の完了後フォロー**: 令和6年度継続事業の完了状況と次期設備更新計画を確認。

- 第1分団屯所更新事業完了後の次期整備計画
