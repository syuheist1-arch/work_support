# 営業支援レポート: 奈義町 / 防災
- 作成日: 2026-06-05
- 対象資料: 令和8年度一般会計当初予算書（r08ippan.pdf）

## エグゼクティブサマリー（5行以内）

- 一般会計81億6,000万円（前年比+21.8%）。消防費228,182千円（前年比△178,049千円）。
- **【最重要案件】消防機庫統合整備事業（設計等委託料20,000千円・緊防債20,000千円充当）**。今年度は設計段階で、工事本体は次年度以降に発注される見込み。
- **【重要案件】自助力向上防災装備品整備事業（29,000千円・業務委託）**。自助装備品の調達・整備に関する大型委託案件。
- **避難施設照明LED化事業（緊防債96,600千円）・小学校体育館改修事業（緊防債11,600千円）**。緊急防災・減災事業債を活用した大型事業が進行中。
- 防災行政無線は令和7年度に大規模更新完了（令和7年度予算233,556千円→令和8年度47,906千円に縮小）。

## 次アクション提案

1. **消防機庫統合整備工事の発注時期確認**: 令和8年度設計完了後、令和9年度の工事発注が見込まれる。設計段階で工事概算額・仕様を把握し早期にアプローチ。
2. **自助力向上防災装備品整備事業の仕様確認**: 29,000千円の業務委託内容（装備品の種類・数量・調達先）を総務課に確認。
3. **避難施設照明LED化事業の工事発注状況確認**: 緊防債96,600千円を充当。設計・工事の発注スケジュールを確認。

## 要確認事項

- 消防機庫統合整備工事の工事発注時期・概算金額
- 自助力向上防災装備品整備事業の具体的内容（29,000千円の委託内容）
- 避難施設照明LED化事業の工事業者選定状況
