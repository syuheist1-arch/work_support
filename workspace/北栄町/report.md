# 営業支援レポート: 北栄町 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度当初予算（全員協議会資料「今年のしごと」）

## エグゼクティブサマリー（5行以内）

- 一般会計139億3,400万円（R7比+28.7%・過去最大）だが、青山剛昌ふるさと館再整備25.8億円・中央公民館大栄分館建替11.6億円が主因で防災費自体の増額は限定的。
- 消防費は広域連合負担金250,589千円（R7比+28,965千円）が中心。消防施設設置事業12,556千円（+3,688千円）は消火栓修繕・維持管理8,724千円含む。
- **災害対策事業が19,051千円（R7比+13,902千円・270%増）。ハザードマップ作成委託13,090千円が今年度の新規主要案件。**
- 防災行政無線は維持管理のみ（5,147千円）。新規整備・デジタル化の記載なし。
- 緊急自然災害防止対策事業53,500千円（道路舗装補修・緊急自然災害防止対策事業債充当）と道路メンテナンス事業28,000千円（橋梁定期点検58橋・修繕1橋）が土木防災系の主要事業。

## 議会・首長の関心（事実ベース）

※ 議事録は今回未収集。予算資料から読み取れる方針のみ記載。

- 予算概要の「安全で持続可能なまちづくり」の柱に「物価高と災害から町民の日常を守ります」を掲げ、災害対策事業を大幅拡充（+270%）。
- ハザードマップ更新・備蓄品整備・感震ブレーカー補助を同一事業（災害対策事業）にまとめて計上。
- 道路舗装・橋梁修繕の計画的インフラ整備を緊急自然災害防止対策事業債で継続。
