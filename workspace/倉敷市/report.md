# 営業支援レポート: 倉敷市 / 防災
- 作成日: 2026-06-04
- 対象資料: 令和8年度当初予算概要版

## エグゼクティブサマリー（5行以内）

- **消防指令設備更新委託料390,500千円（常備消防施設維持補修内）が最重要案件。**
- **消防救急デジタル無線整備134,750千円（新規・保守期間満了）。**
- 消防費合計6,367,167千円（前年比+16.6%・+905,247千円）。常備消防施設費が前年の約1.9倍と大幅増。
- 防災拡声塔（防災行政無線）を令和8年3月に廃止。プッシュ型FMラジオ通知事業（緊急告知FMラジオ購入助成）に移行。
- 防災備蓄倉庫（玉島柏島）整備218,850千円。高規格救急車3台154,827千円・消防ポンプ車CD-Ⅰ 2台（常備）120,208千円。
