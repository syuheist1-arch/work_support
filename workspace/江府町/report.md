# 営業支援レポート: 江府町 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度一般会計予算書

## エグゼクティブサマリー（5行以内）

- **J-ALERT設備購入費8,932千円（緊急防災・減災事業債8,900千円）が今年度の最重要案件。** 全国瞬時警報システムの更新整備。
- **ハザードマップ作成委託料2,794千円が防災費に計上。** 洪水・土砂等のハザードマップ更新。
- 橋梁修繕工事56,000千円・道路修繕工事243,000千円が道路維持費内に計上（合計約299,000千円）。
- 消防費合計113,926千円（R7比△17,670千円）。非常備消防費のうち西部広域行政管理組合負担金67,394千円が大部分。消防施設費はR7比△16,023千円と大幅減（前年度の大型整備の反動）。
- 防災行政無線は保守・維持管理のみ（無線保守委託2,338千円）。新規大規模整備なし。

## 議会・首長の関心（事実ベース）

※ 議事録は今回未収集。予算資料から読み取れる方針のみ記載。

- J-ALERT設備の更新を緊急防災・減災事業債8,900千円で実施。全国的な更新時期に合わせた対応。
- ハザードマップ更新委託を防災費に新規計上。住民への防災情報提供を強化。
- 消防施設費はR7大型整備（22,650千円）の反動減。消防施設の整備はR7に集中実施済み。
