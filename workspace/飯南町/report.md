# 営業支援レポート: 飯南町 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度当初予算概要

## エグゼクティブサマリー（5行以内）

- **消防設備整備事業（消防車両更新2台）20,565千円（緊急防災・減災事業債20,300千円）が最重要案件。** 第1分団・第7分団の消防車両更新。
- **ハザードマップ作成・印刷経費2,660千円（新規）。** 浸水想定区域追加対応。防安全交付金1,250千円活用。小規模だが新規計上。
- **防災行政無線臨時管理費4,349千円（新規2件含む）。** 塩谷再送子局修繕・琴弾中継局バッテリー交換（4,112千円）が主体。
- 雲南広域連合臨時負担金（消防）8,002千円に高規格救急自動車整備事業6,333千円・消防通信指令システム更新事業202千円を含む。広域での大型整備も進行中。
- 法面等災害防除事業（小田法面落石対策工事）60,000千円が最大の防災土木案件（社会資本整備総合交付金36,300千円・過疎債23,700千円）。
