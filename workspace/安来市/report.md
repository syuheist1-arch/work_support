# 営業支援レポート: 安来市 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度当初予算の概要・予算に関する説明書

## エグゼクティブサマリー（5行以内）

- **消防指令システム更新事業226,000千円（債務負担行為・地方債225,900千円）が最重要案件。** 令和8年度中に発注・契約。大型案件であり早期アプローチが必須。
- **消防施設費92,310千円（市債71,700千円）。** 常備消防施設費66,000千円（緊急消防援助隊設備整備費補助15,081千円含む）・非常備消防施設費26,310千円。
- **防災・防犯諸費45,641千円（うち防災費40,896千円）。** 原子力防災安全等対策基金繰入43,200千円を財源に充当。島根原発立地市ならではの防災体制整備。
- 消防費合計978,427千円（R7比+24,898千円）。常備消防費が45,772千円増（職員人件費等）。
- 原子力防災交付金が県から60,000千円（交付金40,000千円+人件費20,000千円）計上。原子力防災体制への継続投資あり。

## 議会・首長の関心（事実ベース）

※ 議事録は今回未収集。予算資料から読み取れる方針のみ記載。

- 消防指令システム更新を債務負担行為226,000千円で設定。R8年度内に大型更新を実施。
- 島根原発立地市として原子力防災交付金（県から計60,000千円）・基金繰入金（43,200千円）を継続活用。
- 常備消防施設費に緊急消防援助隊設備整備費補助（15,081千円）を確保。
- 一般会計がR7比△1.2%減のなか消防費は+24,898千円増。消防体制維持に積極的。
