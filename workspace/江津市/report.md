# 営業支援レポート: 江津市 / 防災
- 作成日: 2026-06-03
- 対象資料: 令和8年度当初予算のあらまし及び事業の概要

## エグゼクティブサマリー（5行以内）

- **防災マップ更新（委託19,217千円＋印刷5,720千円）が今年度最重要案件。** 防災減災対策費34,168千円（R7比+27,702千円・大幅増）の主因。R8予算化済み。
- **江津邑智消防組合本部庁舎・訓練棟改修工事144,837千円を含む広域消防事業負担金605,673千円。** 大型改修案件。組合への営業アプローチが必要。
- **消防施設整備事業13,694千円（市債7,700千円）。** 消火栓設置等負担金7,703千円・本町消防ポンプ庫解体工事4,913千円・消防ホース1,078千円を含む。
- 橋梁長寿命化事業が269,000千円（R7比+200,800千円・大幅増）。国庫157,410千円・市債101,800千円。橋梁補修・点検の大型案件。
- 令和8年度は市長改選年のため骨格的予算。政策的経費は改選後補正対応のため追加案件発生の可能性あり。

## 議会・首長の関心（事実ベース）

※ 議事録は今回未収集。予算資料から読み取れる方針のみ記載。

- 市長改選年のため骨格予算。政策的案件は改選後補正予算で対応予定。
- 防災マップ更新（+27,702千円の大幅増）を計上。島根県浸水想定区域の拡大に対応。
- 江津邑智消防組合の本部庁舎・訓練棟改修（144,837千円含む）を反映した負担金増加。
- 橋梁長寿命化事業が前年比+200,800千円の大幅増。橋梁維持管理を重点化。

## 次アクション提案

1. **【令和8年度内・最優先】危機管理担当課への「防災マップ更新委託19,217千円」発注確認**: R8大幅増の主因。発注時期・仕様・入札方法を確認。江津市役所TEL: 0855-52-7290。
2. **【要確認】江津邑智消防組合本部庁舎・訓練棟改修工事（144,837千円）**: 組合への直接アプローチで工事内容・機器調達の有無を確認。江津邑智消防組合TEL: 0855-52-2729。
3. **【令和8年度内】橋梁長寿命化事業（269,000千円）の発注確認**: 橋梁補修工事・点検委託の発注時期・入札条件を建設課へ確認。
4. **【要注視】改選後補正予算（令和8年6月以降）**: 骨格予算のため補正で防災関連案件が追加の可能性。公告一覧の定期チェックが重要。
