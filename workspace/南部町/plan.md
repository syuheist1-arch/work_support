# リサーチプラン: 鳥取県西伯郡南部町 / 防災

## 1. 調査目的
鳥取県南部町（人口約9千人の小規模自治体）における令和7・8年度の防災関連予算・議会議論・入札動向を一次情報から把握し、小規模町村に適した防災ソリューション（避難所整備・共同調達・防災情報システム等）の新規提案先・提案タイミングを発掘する。推測を排し、予算書・議事録・入札公告に裏付けられた事実ベースで営業機会を特定する。

## 2. 収集対象（一次情報）
- 予算書: 令和7年度当初予算、令和7年度補正予算（第1号以降、可能な範囲全て）、令和8年度当初予算（編成済み・公表分があれば）
  - なぜ: 防災費の規模・新規/継続事業・財源（国土強靱化交付金等）を確認し、提案余地と予算化サイクルを把握するため。
- 議会会議録: 令和7年第1回（3月）定例会〜直近定例会、防災・総務関連常任委員会、一般質問
  - なぜ: 予算書に現れない課題認識・未着手ニーズ・首長/担当課の方針を把握するため。
- 入札公告・契約結果: 令和7〜8年度の防災関連（避難所、備蓄、防災行政無線、ハザードマップ更新、耐震化工事等）
  - なぜ: 実際の調達品目・規模・落札傾向・発注時期を確認し、参入余地と競合を把握するため。

### 防災必須観点チェックリスト（収集役へ漏れ防止指示）
- 地域防災計画 / 国土強靱化地域計画
- 治水・河川・浸水対策 / 土砂災害（中山間地のため土砂災害は重点）
- 建築物・橋梁・上下水道の耐震化
- 避難所・指定緊急避難場所 / 福祉避難所
- ハザードマップ / 防災情報システム / 防災行政無線（戸別受信機等）
- 備蓄 / 物資 / 受援計画 / BCP
- 消防・救急 / 消防団 / 自主防災組織（広域消防＝鳥取県西部広域行政管理組合の可能性に留意）
- 防災教育・訓練

### 留意事項（事実確認の前提）
- 広域消防・常備消防は一部事務組合（西部広域）が担う可能性が高く、町単独予算に消防本部費が計上されない場合あり → 収集役に「常備消防の所管がどこか」を確認させる。
- 公式情報源（南部町公式サイト・例規・入札情報ページ）のURLは創作せず、収集役に探索・特定させる。

## 4. 各エージェントへの指示文（コピペ用）

### → collector-budget
鳥取県西伯郡南部町の公式サイトおよび公開予算資料から、以下を収集し workspace/南部町/budget_raw.md に保存せよ。
- 対象: 令和7年度当初予算、令和7年度補正予算（全号）、令和8年度当初予算（公表分があれば）
- 抽出範囲: 「2.防災必須観点チェックリスト」の全8観点に該当する歳出（款・項・目・事業名・金額・財源内訳）。特に避難所整備、備蓄、防災行政無線/戸別受信機、ハザードマップ、土砂災害・治水、耐震化、自主防災組織・消防団。
- 常備消防の所管（南部町単独か西部広域等の一部事務組合か）を必ず確認し明記。
- 国土強靱化交付金・緊急防災減災事業債など財源の充当があれば記録。
- URLは創作せず、参照した実在ページのURLと取得日を必ず併記。見つからない項目は「未確認」と明記し、推測で埋めないこと。

### → collector-minutes
南部町議会の会議録（令和7年第1回定例会以降、直近まで）と関連常任委員会から、防災に関する発言を収集し workspace/南部町/minutes_raw.md に保存せよ。
- 抽出対象: 一般質問・委員会質疑のうち、避難所、福祉避難所、土砂災害・浸水、防災行政無線、ハザードマップ、備蓄、消防団・自主防災組織、地域防災計画/国土強靱化、BCP・受援計画に関するもの。
- 各発言は「会期・日付・質問者/答弁者・要旨・原文該当箇所」を記録。
- 課題として指摘されたが未予算化・検討中の事項を特に明示（提案余地の核となるため）。
- 会議録のURL・取得日を併記。創作禁止。未公開分は「未公開」と明記。

### → analyst-budget
workspace/南部町/budget_raw.md を読み、workspace/南部町/budget_analysis.md に整理せよ。
- 8観点ごとに金額を集計し、令和7→8年度の増減を表化。
- 各事業を「新規/継続/拡充/縮小」に分類。
- 国費・地方債等の特定財源が付く事業を抽出（提案時の財源根拠になる）。
- 単独町負担分と広域組合負担分を分離。
- 事実とデータ欠落（未確認項目）を明確に区別して記載。

### → analyst-needs
workspace/南部町/budget_analysis.md と workspace/南部町/minutes_raw.md を突合し、workspace/南部町/needs_analysis.md に提案機会を整理せよ。
- 「議会で課題提起されたが予算未計上」の領域を最優先の提案機会として抽出。
- 小規模町村特性（共同調達・広域連携・省人化/クラウド型システム）に適合する機会を強調。
- 各機会に「根拠（予算/議事録の該当）」「想定提案内容」「想定発注時期」を付す。
- 事実根拠が薄いものは「仮説」と明記。

### → qa-editor
全分析ファイルを統合し、workspace/南部町/report.md に営業向けサマリを作成せよ。
- 構成: (1)エグゼクティブサマリ (2)防災予算全体像 (3)観点別の動向 (4)優先提案機会トップ3〜5（根拠・時期付き） (5)出典一覧。
- すべての記述に出典（ファイル/URL）を紐付け、事実と仮説をラベルで明確に区別。
- 出典のない断定・創作URLがあれば差し戻し修正すること。

## 5. 最終成果物
- workspace/南部町/report.md（営業向けサマリ。事実/仮説を区別し、優先提案機会と発注時期を明示）
