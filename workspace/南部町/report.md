# 営業支援レポート: 南部町 / 防災
- 作成日: 2026-06-02
- 対象資料: 予算（なんぶ議会だより第83号・第87号）、議事録（議会だより第83号・第87号の質問答弁要旨 ※会議録PDF全件スキャン画像型のため発言本文は未取得）

## エグゼクティブサマリー（5行以内）

- 令和8年1月の地震で会見地区の滝山水源が濁り、給水袋の半数を消費する実被害が発生。水道水系改善の調査委託が1月臨時議会で可決済みで、令和8年度中に施設整備の方向性が整理される予定。
- 令和8年度当初予算で「防災グッズ購入補助（世帯1/2補助）」が新規計上されるなど、地震契機で防災投資が具体的に動き始めている。
- 「震災に強いまちづくり促進事業」は令和7年度1,597万円・令和8年度も継続計上（議員の賛成討論で「重要」と明示）。
- 「災害時の避難支援及び名簿共有に関する条例（仮称）」制定検討と「令和9年度の災害ボランティアセンター運営訓練」が表明されており、令和8〜9年度が仕込みの好機。
- 消防は鳥取県西部広域行政管理組合が担当しており、町単独の防災ソフト施策（情報発信・備蓄・訓練・要支援者支援）が主な提案領域となる。

## 議会・首長の関心（事実ベース）

※以下はすべて議会だより第83号・第87号の質問答弁要旨に基づく。会議録PDF本文は全件スキャン画像型のためテキスト取得不可。

### 令和8年3月定例議会（議会だより第87号）

- **水道水系改善**: 町長「R8.1地震で滝山水源地の水が濁る被害が発生。給水袋の半数を使用して住民に給水した。R8.1臨時議会で水道水系改善に係る調査委託予算を可決。本年度中に施設整備の方向性を整理する」（三鴨議員・加藤議員質問への答弁）
- **防災グッズ購入補助**: 町長「令和8年度当初予算に世帯1/2補助として計上した」（三鴨議員質問への答弁）
- **要支援者避難・条例**: 「災害時の避難支援及び名簿共有に関する条例（仮称）の制定を進める検討を行う」「令和9年度に災害ボランティアセンターの設置・運営訓練を計画する」（井原議員質問への答弁）
- **情報発信**: 町長「R8.1地震時のテノヒラ役場での情報発信は状況に応じて適切なタイミングで発信した。今後の防災訓練推進と情報発信のあり方を検討する」（﨏田議員質問への答弁）
- **賛成討論**: 「防災対策・震災に強い町づくり促進事業は重要」（令和8年度一般会計予算への議員賛成討論）

### 令和7年3月定例議会（議会だより第83号）

- **ため池監視カメラ**: 町長「町全体としてため池監視カメラの整備を進めている」（井原議員質問への答弁）
- **要支援者避難**: 「鳥取県が定めた要介護支援者避難対策指針に基づき、具体的な避難支援プランの整備に取り組む」（井原議員質問への答弁）
- **防災行政無線**: 令和7年4月1日から天萬庁舎のモーター式サイレン放送を停止。定時音楽放送は継続（板井議員質問）
- **テノヒラ役場**: LINE情報発信サービスの登録者数は約3,700人（﨏田議員質問への答弁）

## 次アクション提案

1. **【最優先・令和8年度内】総務課（防災担当）へのアプローチ**: 水道水系改善の「施設整備の方向性の整理」が令和8年度中に完了予定。整理結果が出る前（遅くとも令和8年秋〜冬）に、水源監視・緊急給水・配水池整備に関するソリューション提案を行い、令和9年度予算要求サイクルに乗せる。接触先: 総務課（法勝寺庁舎2階）TEL: 0859-66-3112
2. **【令和8年6〜7月】「震災に強いまちづくり促進事業」の詳細把握**: 事業内容（耐震化補助かハード整備か）が未確認のため、総務課または入札公告ページで事業詳細を確認し、提案対象かどうかを判断する。
3. **【令和8年度中〜令和9年度】要支援者避難支援・名簿共有条例への仕込み**: 条例制定の検討段階。個別避難計画策定支援・名簿管理システムの提案と、令和9年度「災害ボランティアセンター運営訓練」に向けた支援提案を同期間に実施。
4. **【令和8年6月〜】情報発信強化への提案**: 地震時の情報発信が議会で問題提起され「検討する」と答弁された直後のタイミング。テノヒラ役場（LINE）の到達率向上・多チャネル化の提案書を持参。
