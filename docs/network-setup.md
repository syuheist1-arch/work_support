# ネットワーク設定ガイド（営業支援AIチーム用）

収集エージェント（collector-budget / collector-minutes など）が自治体サイトの
一次情報（予算書・議会会議録）を取得するには、**環境のネットワークアクセス設定**を
変更する必要がある。

## 背景：なぜ取得できなかったか

Claude Code on the web の各環境は「ネットワークアクセスレベル」を1つ持つ。
既定は **Trusted**（許可リスト掲載ドメインのみ：パッケージレジストリ、GitHub、
Anthropic系など）。自治体ドメインは許可リスト外のため、`WebFetch`/`curl` が
HTTP 403 になり、予算PDFや会議録本文に到達できなかった（サイト側の拒否ではない）。

| レベル | 外向き通信 |
|--------|-----------|
| None | 通信不可 |
| Trusted（既定） | 許可リストのドメインのみ |
| **Full** | 任意のドメイン（最も確実） |
| **Custom** | 自分の許可リスト（既定リストを併用可） |

## 対処手順（Web UI）

1. 画面の **クラウドアイコン（現在の環境名が表示されている箇所）** をクリックして
   環境セレクタを開く。
2. 対象環境にカーソルを合わせ、右に出る **設定（歯車）アイコン** をクリック。
3. ダイアログの **Network access** セレクタで、次のどちらかを選ぶ。
   - **Full**：あらゆるドメインを許可（最も手早く確実。まずはこれを推奨）
   - **Custom**：下記「許可ドメイン」を1行ずつ入力し、
     **「Also include default list of common package managers」にチェック**
     （既定の許可リストも残す）。
4. 保存する。

> ⚠️ 重要：環境設定は **新しいセッションから反映** される（セッションごとに
> まっさらなVMが立つため）。設定変更後は **新しいセッションを開始** して再実行すること。
> 現在のセッションには反映されない。

## Custom にする場合の推奨許可ドメイン

### 鳥取県（今回の対象）
```
*.pref.tottori.lg.jp
db.pref.tottori.jp
*.pref.tottori.dbsr.jp
www.kensakusystem.jp
*.tori-info.co.jp
```

### 営業支援で横展開する場合（全国の自治体・官公庁）
```
*.lg.jp        # 全国の地方自治体（市区町村・都道府県）
*.go.jp        # 中央省庁（総務省消防庁・内閣官房 等）
*.dbsr.jp      # 会議録検索システム（DB-Search系を多数の自治体が採用）
```

## 補足：Custom が効かない場合

Custom の許可ドメインが反映されない不具合報告が存在する（egress 許可リストに
 JWT のクレームが渡らない等）。**Custom で 403 が続く場合は Full に切り替える**のが
確実。落ち着いたら Custom に絞り直す運用がよい。

## 設定後の再実行

新セッションで、保存済みの計画に沿って再実行すればよい：

> 「workspace/鳥取県/plan.md の計画どおりに collector-budget と collector-minutes を
>  実行し、その後 analyst-budget / analyst-needs → qa-editor まで回して report.md を作って。」
